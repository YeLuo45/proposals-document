# PRJ-20260509-002 — PixelPal V59: 插件系统落地

## 概述
参照 Hermes Skill Registry，实现插件市场 + 技能注册机制。用户可浏览/安装/启用/停用插件，插件提供扩展能力（API接入、工具集成、新的AI技能）。

## 功能

### P0 — 插件核心框架
**插件结构**（JSON manifest）：
```json
{
  "id": "weather-plugin",
  "name": "天气查询",
  "version": "1.0.0",
  "author": "community",
  "description": "查询实时天气信息",
  "icon": "🌤️",
  "enabled": false,
  "permissions": ["fetch"],
  "manifest": {
    "actions": [
      { "id": "getWeather", "name": "查天气", "params": ["city"] }
    ]
  }
}
```

**存储**：IndexedDB 新建 `plugins` store，存储插件 manifest + 配置

**加载**：App 启动时扫描所有 enabled plugins，注册 action handler

### P1 — 插件市场 UI
**PluginStore 面板**（新增 Tab 或独立页面）：
- 展示插件列表（本地已安装）
- 插件卡片：图标 + 名称 + 描述 + 启用/停用开关
- 点击展开：权限说明 + 配置项 + 卸载

**插件来源**：
- 预置插件（内嵌，几个基础插件）
- 未来可扩展：远程插件市场 URL

### P2 — 插件执行
**Action 触发**：
- 用户在 Chat 输入触发（如"查天气 北京"）
- AI 判断意图 → 调用对应 plugin action
- 结果返回给 AI → 生成自然语言回复

**实现**：
- `src/services/plugins/pluginRegistry.ts` — 管理所有插件 + action 路由
- `src/services/plugins/actionExecutor.ts` — 执行 action（支持 fetch 调用外部 API）
- 插件 action 注册到 AI prompt 或 function calling
