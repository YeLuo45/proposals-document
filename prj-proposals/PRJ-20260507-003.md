# V32 Fix — Chat Failed Data + Memory Blank Box

## Status: in_dev

## Issues

### Issue 1: 聊天框中一直存在失败的数据，即使 /new,/clear,/reset 也清空不了

**Root Cause**: `clearMessages` 只清 `store.messages`，不清 `store.collabMessages`。如果之前开过多人协作（collab），`collabMessages` 中的残留消息仍然显示在聊天区。

**Fix**: 扩展 `clearMessages` 的逻辑，在清空时同时清空 `collabMessages`。或者在 `handleSend` 的 clear 命令处理中，额外调用 `endCollab()`。

**Affected Flow**:
- `ChatPanel.tsx` line 452-455: clear command → `clearMessages()` + `addMessage`
- `store/index.ts` line 302: `clearMessages: () => set({ messages: [] })` — does NOT clear collabMessages

### Issue 2: 记忆的内容框上面存在一个空白框

**Root Cause**: `MemoryPanel.tsx` 中 `AllMemoriesTab` 组件的根 Box 有 `minHeight: 300`，即使 memories 为空也会撑出一个空白区域。条件渲染 `memories.length > 0` 在 minHeight 之后，所以空白区始终存在。

**Fix**: 将 `AllMemoriesTab` 的 `minHeight` 从 300 改为 `undefined`，或者加条件 `memories.length > 0` 时才有 minHeight。同时检查其他 tab 的根 Box 是否有类似问题。

**Affected File**: `src/components/Memory/MemoryPanel.tsx` — `AllMemoriesTab` 根 Box

## Technical Approach

### Fix 1: clearMessages also clears collab state

在 `ChatPanel.tsx` 的 clear 命令处理中，改为调用 `endCollab()` 而不是 `clearMessages()`，因为：
- `endCollab()` 同时清空 `collabSession` 和 `collabMessages`（store/index.ts line 581-585）
- 但 `endCollab()` 不会清空普通 `messages`

更好的方案：创建一个联合清理函数，同时清空两者。

**方案A**: 在 ChatPanel 的 clear handler 中同时调用 `clearMessages()` 和 `endCollab()`
**方案B**: 在 store 层创建一个 `clearAllChat()` 统一方法

推荐方案A，因为简单且不会影响其他地方的逻辑。

### Fix 2: Remove minHeight constraint on AllMemoriesTab

将 `AllMemoriesTab` 根 Box 的 `minHeight: 300` 移除，或改为 `minHeight: memories.length > 0 ? 300 : undefined`。

同时检查其他 tab（EntitiesTab, TimelineTab, InsightsTab, EmotionTimelineTab）是否有类似问题。
