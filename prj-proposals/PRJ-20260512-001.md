# PRJ-20260512-001: PixelPal Skill Marketplace V78

## 1. Concept & Vision

Skill Marketplace 让用户可以上传、分享、发现和安装社区创建的 Skills。将 PixelPal 从"自带技能的工具"升级为"技能生态平台"。参考 astrbot 的插件市场设计，但面向更轻量的 Skill 概念。

核心场景：用户 A 创建了一个"煎蛋计时器"Skill → 上传到市场 → 用户 B 发现并一键安装

## 2. Design Language

- **Aesthetic**: 清新卡片市场风格，与现有暗色主题区分
- **Colors**:
  - Primary: #6366F1 (indigo)
  - Secondary: #8B5CF6 (violet)
  - Accent: #F59E0B (amber for ratings)
  - Background: #F8FAFC (light gray)
  - Card BG: #FFFFFF
  - Text: #1E293B
- **Typography**: Inter for UI, monospace for code previews
- **Motion**: Card hover lift (transform: translateY(-2px)), fade-in for lists

## 4. Features & Interactions

### 4.1 Skill Discovery
- **Search**: Real-time filter by name, description, tags
- **Category tabs**: Filter by SkillCategory
- **Sort**: By popularity (install count), rating, newest
- **Featured**: Editor picks at top

### 4.2 Skill Installation
- One-click install → saves to IndexedDB (same as custom skills)
- Duplicate check: show "Already Installed" if skill.id exists
- Post-install: redirect to My Skills with success toast

### 4.3 Skill Upload Flow
1. User clicks "Share Skill" in My Skills panel
2. Opens upload dialog pre-filled with their skill definition
3. Edit description, tags, example prompts, icon
4. Preview card how it will appear in store
5. Submit → added to community skills (localStorage for MVP)

### 4.4 Ratings & Reviews
- 5-star rating on install (optional modal)
- Text review (optional)
- Display aggregate rating and count on cards
- Reviews stored in localStorage keyed by skillId

### 4.5 Skill Update
- Check for updates on app start (compare version strings)
- "Update Available" badge in My Skills
- One-click update replaces skill definition

## 6. Technical Approach

### 6.1 New Dependencies
- None (pure React + existing infrastructure)

### 6.2 Data Model

```typescript
// Stored in IndexedDB (skillStorage already exists)
// Community skills stored separately

interface MarketplaceSkill extends SkillDefinition {
  installCount: number;
  ratings: SkillRating[];
  avgRating: number;
  uploadedAt: string;
  updatedAt: string;
}

interface SkillRating {
  userId: string;
  rating: 1 | 2 | 3 | 4 | 5;
  review?: string;
  createdAt: string;
}

// Routes
// GET  /skill-store          → MarketplacePage
// POST /skill-store/upload  → SkillUploadDialog (or navigate to)
// GET  /skill-store/:id     → SkillDetailDialog
```

### 6.3 Storage Strategy (MVP)
- Community skills: `localStorage.setItem('community-skills', JSON.stringify([...]))`
- Ratings: `localStorage.setItem('skill-ratings', JSON.stringify({[skillId]: [...]}))`
- Pre-populated with 5-8 sample marketplace skills for demo
