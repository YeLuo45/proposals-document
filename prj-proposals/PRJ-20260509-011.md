## 1. 背景与目标

V70实现了 `EmotionBehaviorEngine`（情绪→行为映射），但目前是独立的，未与Agent执行流程绑定。

V67实现了 `memoryManager`（记忆上下文注入）。

**目标：** 将情感检测结果自动注入Agent执行上下文，让Agent在分解任务时能感知用户情绪状态。

---

## 2. 现状分析

### 2.1 EmotionBehaviorEngine（V70）
- 独立模块，不影响主流程
- `getRecommendedAction(emotion, confidence)` 返回 `EmotionAction`
- 30秒冷却机制

### 2.2 AgentExecutor（V64）
- `executeTask(taskId)` — 执行任务
- `decomposeGoal()` — LLM分解目标为步骤
- 已有 `memoryManager.getContextForPrompt()` 注入记忆上下文

### 2.3 缺失环节
```
emotionEngine 检测 → EmotionBehaviorEngine 映射 → 结果未注入Agent
```

## 3. 功能设计

### 3.1 情感上下文类型

```typescript
// src/services/agent/types.ts 新增

export interface EmotionContext {
  detected: boolean
  emotion: string | null      // 'happy' | 'calm' | 'anxious' | 'angry' | 'sad' | 'excited' | 'exhausted' | 'unknown'
  confidence: number
  recommendedAction: {
    type: 'comfort' | 'encourage' | 'calm' | 'activate' | 'focus_suggest' | 'none'
    message: string
  } | null
  triggered: boolean           // 本次任务是否已触发情感响应
}
```

### 3.2 EmotionContextInjector

```typescript
// src/services/agent/emotionContextInjector.ts

import { emotionEngine } from '../emotion/emotionEngine'
import { emotionBehaviorEngine } from '../emotion/EmotionBehaviorEngine'
import type { EmotionContext } from './types'

class EmotionContextInjector {
  private currentContext: EmotionContext = {
    detected: false,
    emotion: null,
    confidence: 0,
    recommendedAction: null,
    triggered: false,
  }

  // 检测并更新情感上下文
  detectEmotion(): EmotionContext {
    // 从emotionEngine获取当前情绪
    const result = emotionEngine.analyze()  // 假设analyze()返回当前情绪

    if (result) {
      const action = emotionBehaviorEngine.getRecommendedAction(result.type, result.confidence)
      this.currentContext = {
        detected: true,
        emotion: result.type,
        confidence: result.confidence,
        recommendedAction: action
          ? { type: action.action, message: action.message }
          : null,
        triggered: false,
      }
    }

    return this.currentContext
  }

  // 获取当前情感上下文
  getContext(): EmotionContext {
    return this.currentContext
  }

  // 标记已触发（防止重复触发）
  markTriggered(): void {
    this.currentContext.triggered = true
  }

  // 格式化用于LLM提示词
  formatForPrompt(): string {
    const ctx = this.currentContext
    if (!ctx.detected || !ctx.emotion) {
      return ''
    }

    let prompt = `\n[用户情绪状态]\n情绪: ${ctx.emotion} (置信度: ${(ctx.confidence * 100).toFixed(0)}%)`

    if (ctx.recommendedAction && ctx.recommendedAction.type !== 'none') {
      prompt += `\n建议响应方式: ${ctx.recommendedAction.type}`
      prompt += `\n建议消息: "${ctx.recommendedAction.message}"`
    }

    return prompt
  }
}

export const emotionContextInjector = new EmotionContextInjector()
```

### 3.3 AgentExecutor集成

修改 `src/services/agent/agentExecutor.ts`：

在 `decomposeGoal()` 构建提示词时：

```typescript
// 在现有memoryContext之后添加emotionContext
const memoryContext = memoryManager.getContextForPrompt()
const emotionContext = emotionContextInjector.formatForPrompt()

const prompt = `
任务: ${task.goal}
${memoryContext ? `记忆上下文:\n${memoryContext}` : ''}
${emotionContext}
请分解任务为具体执行步骤。
`
```

在 `executeTask()` 完成后：

```typescript
// 检查是否需要发送情感响应消息
const emotionCtx = emotionContextInjector.getContext()
if (emotionCtx.recommendedAction && !emotionCtx.triggered) {
  // 通过platformAdapter发送响应
  const platformAdapter = getCurrentPlatformAdapter()  // 需要获取当前adapter
  if (platformAdapter && emotionCtx.recommendedAction.type !== 'none') {
    await platformAdapter.sendMessage(emotionCtx.recommendedAction.message)
    emotionContextInjector.markTriggered()
  }
}
```

### 3.4 获取当前PlatformAdapter

由于AgentExecutor不直接依赖PlatformAdapter，创建一个小hook：

```typescript
// src/platform/agentPlatformHook.ts

let currentAdapter: PlatformAdapter | null = null

export function setCurrentPlatformAdapter(adapter: PlatformAdapter): void {
  currentAdapter = adapter
}

export function getCurrentPlatformAdapter(): PlatformAdapter | null {
  return currentAdapter
}
```

在 `App.tsx` 或入口初始化时调用 `setCurrentPlatformAdapter(webAdapterInstance)`。

## 4. 非功能需求

- 情感上下文仅影响LLM提示词，不阻塞执行流程
- 情感响应消息异步发送，不影响任务执行时间
- 冷却机制由EmotionBehaviorEngine控制
- 与现有模块松耦合
