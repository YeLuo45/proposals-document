## 1. 背景

当前RecommendationEngine和RecommendationPanel已实现，但与ChatPanel完全独立。用户无法看到推荐，也无法通过推荐触发操作。

**目标：** 将RecommendationPanel集成到ChatPanel中，让用户在聊天界面看到个性化推荐，并可通过点击推荐直接执行。

---

## 2. 功能设计

### 2.1 修改ChatPanel.tsx

在消息列表下方添加推荐面板：
- 用户发送消息后，提取偏好并更新推荐
- 推荐面板在空闲时显示
- 点击推荐项触发对应action

### 2.2 偏好提取集成

用户发送消息时，自动调用 preferenceEngine.extractFromInteraction() 记录偏好：

```typescript
// 在ChatPanel handleSend中
const handleSend = async (message: string) => {
  // 提取用户偏好
  preferenceEngine.extractFromInteraction({
    id: Date.now().toString(),
    type: 'message',
    content: message,
    timestamp: Date.now(),
  })

  // ... 原有逻辑 ...
}
```

### 2.3 推荐面板集成

在ChatPanel组件底部或侧边添加推荐面板：

```typescript
// 在ChatPanel组件中添加
import { RecommendationPanel } from '../Recommendation/RecommendationPanel'
import { recommendationEngine } from '../../services/recommendation/recommendationEngine'

// 组件内部
const [recommendations, setRecommendations] = useState([])

useEffect(() => {
  const recs = recommendationEngine.getActiveRecommendations(3)
  setRecommendations(recs)
}, [messages]) // 消息变化时更新推荐

// 渲染
return (
  <div className="chatpanel">
    {/* 消息列表 */}
    <div className="messages">
      {messages.map(...)}
    </div>

    {/* 推荐面板 */}
    <RecommendationPanel onExecute={(action) => {
      if (action.startsWith('/multi')) {
        // 触发多Agent
        triggerMultiAgent(action.replace('/multi ', ''))
      } else if (action === 'enable_memory') {
        // 启用记忆
        enableMemory()
      } else {
        // 其他action
        handleSend(action)
      }
    }} />

    {/* 输入框 */}
    <div className="input-area">
      <input ... />
    </div>
  </div>
)
```
