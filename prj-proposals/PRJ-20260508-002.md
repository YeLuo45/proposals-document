# PRJ-20260508-002 — PixelPal V55: 记忆持久化 + RAG 语义搜索

## 概述
聊天记录持久化到 IndexedDB，语义搜索历史对话。解决：刷新页面聊天记录丢失、无法检索历史内容的问题。

## 需求池

### P0 — IndexedDB 持久化
**功能**：刷新页面后聊天记录不丢失，Tasks/Memory/Calendar 数据也持久化。

**技术方案**：
- 使用 `idb` 库（轻量 IndexedDB wrapper）管理数据库
- 四个 objectStore：`messages`、`tasks`、`memory`、`events`
- 关键时机：
  - 发送消息后 → 写入 messages store
  - 页面加载时 → 从 IndexedDB 读取并还原到 store
  - 启动时自动 open DB

**文件**：
- `src/services/storage/db.ts` — 新建，IndexedDB 初始化 + CRUD
- `src/services/storage/messageStorage.ts` — 新建，消息存储逻辑
- `src/components/ChatPanel/ChatPanel.tsx` — 加载时从 DB 读取消息

---

### P1 — 语义搜索历史对话
**功能**：用户输入关键词，AI 语义检索相关历史对话。

**技术方案**：
- 使用嵌入向量（Embedding）做语义相似度检索
- 调用 MiniMax Embedding API 将历史消息向量化，存储向量 + 原文
- 搜索时：用户 query → 向量化 → 在向量库中 top-k 检索 → 返回相关消息 + 对应时间

**注意**：当前对话上下文来自 `messages` store，历史检索只用于"搜索历史"场景。

**文件**：
- `src/services/rag/embedding.ts` — 新建，Embedding API 调用
- `src/services/rag/retrieval.ts` — 新建，向量检索逻辑
- `src/components/ChatPanel/ChatPanel.tsx` — 添加"搜索历史"入口
- `src/components/Memory/MemoryPanel.tsx` — 历史检索结果展示

---

### P2 — 记忆自动归档
**功能**：按周/月自动归档聊天记录摘要到 Memory 面板。

**交互流程**：
1. 每周日 24:00（或用户触发）自动总结本周对话
2. 生成摘要写入 Memory 面板
3. 超过 30 天的旧消息可选择清理或归档

**文件**：
- `src/services/summary/weeklySummary.ts` — 新建
- `src/components/Memory/MemoryPanel.tsx` — 归档视图
