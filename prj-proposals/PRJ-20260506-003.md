# PRD: PixelPal V29 收拢时 Floating Toggle Button

## 需求

侧边栏收拢后，整个 52px 栏消失，改用 floating toggle button 触发展开。

## 逻辑

- **展开状态**：侧边栏 160px 显示，点击顶部 ChevronLeft 收拢
- **收拢状态**：侧边栏完全隐藏，出现一个 floating toggle button（固定在内容区左下角）
- 点击 floating button → 展开侧边栏（同时 floating button 消失）
- 侧边栏展开后，顶部 ChevronLeft 可再次收拢

## 实现方案

### 1. MainPage.tsx

不再传递 `collapsed` prop 给 Sidebar，而是：
- 展开时渲染完整 Sidebar
- 收拢时不渲染 Sidebar，改为渲染 floating button

### 2. Floating Toggle Button

位置：内容区左下角，`position: fixed`
样式：圆形按钮，40px，背景色 rgba(15,10,30,0.95)，带 ChevronRight 图标
Z-index：高于内容区

### 3. Sidebar.tsx

不再需要 `collapsed` prop。移除展开/收拢的 transition 逻辑（因为整个组件会显示/隐藏）。

## 验收标准

1. 侧边栏展开时，点击 ChevronLeft 收拢 → 侧边栏消失，floating button 出现
2. floating button 点击 → 侧边栏展开，floating button 消失
3. floating button 始终在内容区左下角，不随页面滚动移动
4. 移动端保持原有 Drawer 行为不变
