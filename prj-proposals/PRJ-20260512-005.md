# PRJ-20260512-005: PixelPal Knowledge Base RAG V82

## 1. Concept & Vision

Knowledge Base 让 PixelPal 的 Agent 能够持久化存储和检索知识。用户可以上传文档（txt/md/pdf）、添加网页内容、手动输入笔记，Agent 在回答时会自动检索相关知识作为上下文（RAG - Retrieval Augmented Generation）。参考 astrbot 的知识库设计。

## 2. Design Language

- 知识库页面：文档列表 + 检索框 + 预览面板
- 浅色主题，与Provider设置一致

## 4. Features & Interactions

### 4.1 Document Sources

```typescript
interface KnowledgeSource {
  id: string;
  type: 'text' | 'file' | 'url' | 'note';
  title: string;
  content: string;        // processed text
  metadata: {
    createdAt: string;
    updatedAt: string;
    source?: string;      // URL or filename
    tags: string[];
    size: number;         // char count
  };
}
```

### 4.2 Source Types

1. **Text Input** — Direct paste/type of text content
2. **File Upload** — Support .txt, .md, .pdf (basic text extraction)
3. **Web URL** — Fetch and extract text from URL
4. **Note** — Quick note with title and content

### 4.3 Chunking Strategy

- Documents split into paragraphs (~500 chars per chunk)
- Overlap: 50 chars between chunks
- Store: chunk text + source ID + chunk index

```typescript
interface TextChunk {
  id: string;
  sourceId: string;
  index: number;
  text: string;
  embedding?: number[];  // computed when indexed
}
```

### 4.4 Embedding & Retrieval

- Use provider's `embed()` method to vectorize chunks
- For providers without embed: use TF-IDF fallback (localStorage based)
- Retrieval: cosine similarity top-K results

```typescript
interface RetrievalResult {
  chunk: TextChunk;
  source: KnowledgeSource;
  score: number;  // 0-1 similarity
}
```

### 4.5 Chat Integration

- When chat message sent, automatically retrieve relevant knowledge
- Retrieved chunks injected as context in `buildRAGContext()`
- User can toggle RAG on/off per conversation
- RAG context shown in chat as system message

### 4.6 Search & Browse

- Full-text search across all sources
- Filter by source type, date, tags
- Click source to preview full content

## 6. Technical Approach

### 6.1 New Files

- `src/services/rag/ragService.ts` — core RAG: chunk, index, retrieve
- `src/services/rag/embeddingService.ts` — embed text using provider or TF-IDF fallback
- `src/services/rag/sourceStorage.ts` — IndexedDB for KnowledgeSource + chunks
- `src/services/rag/index.ts` — exports
- `src/pages/KnowledgePage.tsx` — main page
- `src/components/Knowledge/SourceList.tsx`
- `src/components/Knowledge/SourceCard.tsx`
- `src/components/Knowledge/AddSourceDialog.tsx`
- `src/components/Knowledge/RetrievalPanel.tsx`
- `src/components/Knowledge/DocumentPreview.tsx`
- `src/data/sampleKnowledge.ts` — sample sources for demo

### 6.2 Update Files

- `src/services/ai/model-registry-adapter.ts` — expose embed() method
- `src/pages/MainPage.tsx` — add Knowledge nav link or sidebar item
- `src/components/ChatPanel/ChatPanel.tsx` — call buildRAGContext before chat

### 6.3 Storage

**IndexedDB stores:**
- `pixelpal-knowledge-sources` — KnowledgeSource[]
- `pixelpal-knowledge-chunks` — TextChunk[] (with embeddings)

**Embedding approach:**
- If provider has `embed()` method → use it (best quality)
- If not → TF-IDF local (simple, no API needed)
