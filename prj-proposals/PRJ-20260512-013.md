# PRD: PixelPal V90 — Persona Deepening

## 1. Concept & Vision

深化Persona系统，增加**记忆持久化**和**人格进化**。Persona不再只是预设角色，而是能随着对话学习成长、形成独特记忆的虚拟人格。核心：让每个Persona都像真实的朋友，有记忆、有性格演变。

## 2. Core Features

### 长期记忆
- Persona's对话记忆持久化（关键事件、偏好、习惯）
- 记忆强度衰减曲线（重要记忆长期保留）
- 记忆检索：聊到相关内容时自动触发回忆
- 记忆编辑：用户可查看/删除Persona的记忆

### 人格进化
- Persona根据对话内容微调性格参数
- 进化轨迹可视化（外显/内敛、理性/感性等维度变化）
- 关键决策点：人格重大转变需用户确认
- 人格快照：可回溯到之前的人格状态

### 情感记忆
- 记录与Persona的重要情感时刻
- 纪念日提醒（"今天是你们第一次聊天的日子"）
- 情感状态追踪（开心/难过/激动的时刻）
- 情感共情升级：Persona记住用户的情绪模式

### 关系建模
- 用户-Persona关系等级（陌生→熟悉→朋友→挚友）
- 关系影响对话风格（熟悉后更亲密）
- 共同记忆：双方都参与的事件记忆更深

## 3. Data Model

```typescript
interface PersonaMemory {
  id: string;
  personaId: string;
  content: string;
  importance: number; // 0-10
  createdAt: number;
  lastAccessedAt: number;
  accessCount: number;
  tags: string[];
  type: 'event' | 'preference' | 'fact' | 'emotion';
}

interface PersonaEvolution {
  id: string;
  personaId: string;
  timestamp: number;
  personalitySnapshot: PersonalityVector;
  trigger: string; // 什么导致这次进化
  userConfirmed: boolean;
}

interface PersonalityVector {
  openness: number; // 开放性 0-100
  conscientiousness: number; // 尽责性
  extraversion: number; // 外向性
  agreeableness: number; // 宜人性
  stability: number; // 情绪稳定性
  // 扩展维度
  humor: number;
  empathy: number;
  creativity: number;
}

interface RelationshipLevel {
  level: 'stranger' | 'acquaintance' | 'friend' | 'close';
  intimacy: number; // 0-100
  trust: number; // 0-100
  sharedMemories: number;
}
```

## 4. Technical Changes

### New Services
- `src/services/persona/memoryStore.ts` — 记忆存储 + 检索
- `src/services/persona/memoryManager.ts` — 记忆生命周期管理
- `src/services/persona/personalityEngine.ts` — 人格向量 + 进化
- `src/services/persona/relationshipTracker.ts` — 关系建模

### Memory Algorithm
- TF-IDF + 重要性评分
- 记忆强度 = 重要性 × 访问频率 × 时间衰减
- 低于阈值记忆进入"模糊记忆"状态

### UI Components
- `PersonaMemoryPanel.tsx` — 记忆浏览器（时间线视图）
- `PersonalityChart.tsx` — 人格雷达图 + 进化趋势
- `RelationshipMeter.tsx` — 关系等级 + 亲密度进度条
- `MemoryEditDialog.tsx` — 记忆编辑/删除

### Constraints
- 浅色主题
- 向后兼容V21+ Persona系统
- 隐私：用户数据仅本地存储
