# V32 多语言支持增强 PRD

## 背景
PixelPal i18n 基础设施已完成（en.json/zh.json 各 511 keys），但源码中仍有大量硬编码中文字符串，影响英文用户体验。

## 目标
消除源码中的硬编码中文字符串，完善多语言 UI。

### 不需要 i18n 化的文件
- 数据 store（favoritesStore.ts, mallStore.ts）：纯数据操作，无 UI 字符串
- presetScenes.ts：场景数据模型，保留中英混合
- ActionTypes.ts：常量定义文件，无运行时字符串

### 保留硬编码的情况
- 调试日志（console.log）
- 错误消息（内部 throw）
- 文件路径/URL
- 公式/计算逻辑中的数字

## 实现方案
1. 遍历 30 个文件，识别硬编码中文字符串
2. 在 en.json/zh.json 补充缺失的 i18n key
3. 替换 `t('key')` 调用
4. 验证 `npm run build` 通过
5. GitHub Pages 部署验证

## 验收标准
- [ ] 0 个硬编码中文字符串（搜索 `[\u4e00-\u9fff]` 无结果）
- [ ] npm run build 通过
- [ ] GitHub Pages 部署成功
- [ ] 中英文切换正常
