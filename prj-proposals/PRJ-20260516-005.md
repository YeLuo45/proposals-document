## Requirements

### R1: 模型单次成本配置
在 store 中配置每个模型的单次调用成本（token/次）：
```javascript
MODEL_COST = {
  'image-01': { tokens: 100, unit: '次' },
  'image-02': { tokens: 50, unit: '次' },
  'music-2.6': { tokens: 200, unit: '次' },
  'music-02': { tokens: 150, unit: '次' },
  'speech-01': { tokens: 80, unit: '次' },
  'speech-02': { tokens: 120, unit: '次' },
}
```

### R2: 累计消费统计
在 store 增加 `totalUsage: { [modelId]: count }`：
- 与 `modelUsage` 合并（`modelUsage` 已有计数，直接复用）
- 计算总调用次数和总"成本"

### R3: 额度管理 UI
在"我的"页面增加：
```html
<div class="quota-section">
  <h3>📊 API 使用概览</h3>
  <div class="usage-list">
    <div class="usage-row">
      <span class="model">image-01</span>
      <span class="bar" style="width: 60%"></span>
      <span class="count">12次</span>
    </div>
    <!-- ... 各模型 ... -->
  </div>
  <div class="total">总调用: 45次</div>
</div>
```

### R4: 成本估算（简单数字）
每个模型固定"消耗"值，不连接真实计费 API，只做本地估算展示。
