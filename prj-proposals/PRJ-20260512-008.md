# PRD: PixelPal V85 — Skill Ecosystem Enhancement

## 1. Concept & Vision

完善Skill生态体系，增加**评分系统、版本管理、依赖解析**，让Skill从可用变成真正好用。开发者能发布、用户能选择、系统能维护。

## 2. Core Features

### Skill评分系统
- 用户可对Skill评分（1-5星）
- 使用统计（调用次数、活跃用户）
- 评论区（用户反馈）

### Skill版本管理
- Semantic versioning（major.minor.patch）
- 版本历史记录
- 一键回滚到上一版本
- 自动提示新版本更新

### Skill依赖解析
- Skill声明依赖其他Skill
- 安装时自动拉取依赖
- 依赖冲突检测
- 循环依赖保护

### Skill市场增强
- 搜索 + 分类过滤
- 热门推荐、最新发布
- 开发者主页

## 3. Data Model

```typescript
interface SkillMetadata {
  id: string;
  name: string;
  version: string; // semver
  author: string;
  description: string;
  category: SkillCategory;
  tags: string[];
  dependencies: SkillDependency[];
  stats: {
    installs: number;
    rating: number;
    ratingsCount: number;
    calls: number;
  };
  versions: SkillVersion[];
  reviews: SkillReview[];
}

interface SkillVersion {
  version: string;
  changelog: string;
  createdAt: number;
  manifest: SkillManifest;
}

interface SkillDependency {
  skillId: string;
  versionRange: string; // semver range
}

interface SkillReview {
  id: string;
  userId: string;
  rating: number;
  comment: string;
  createdAt: number;
}
```

## 5. Technical Approach

### New Services
- `src/services/skill/SkillVersionManager.ts` — 版本管理
- `src/services/skill/SkillDependencyResolver.ts` — 依赖解析
- `src/services/skill/SkillRatingService.ts` — 评分统计

### Storage
- `localStorage` 存储用户评分、版本记录

### Constraints
- 不保留API keys
- 浅色主题
- 向后兼容现有Skill系统
