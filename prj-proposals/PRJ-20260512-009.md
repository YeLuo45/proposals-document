# PRD: PixelPal V86 — Mobile Adaptation

## 1. Concept & Vision

PixelPal从桌面端扩展到移动端。核心是**响应式布局**而非独立App——一次开发，多端适配。移动端保留核心功能（对话、Persona、Agent），精简次要面板，确保在小屏上操作流畅。

## 2. Core Principles

- **响应式优先**: CSS媒体查询 + 条件渲染，不写两套UI
- **功能分级**: 桌面全功能 vs 移动精简核心
- **手势支持**: 侧滑返回、滑动切换
- **性能优化**: 移动端减少动画、延迟加载非关键组件

## 3. Breakpoints

| 断点 | 宽度 | 布局 |
|------|------|------|
| Mobile | < 640px | 单栏，底部Tab |
| Tablet | 640-1024px | 双栏，折叠侧边栏 |
| Desktop | > 1024px | 三栏，全侧边栏 |

## 4. Mobile-Specific Components

### BottomTabNav
- 移动端底部Tab替代侧边栏
- 4个Tab：Chat / Persona / Agent / Settings
- 图标 + 文字

### MobileChatPanel
- 全屏聊天界面
- 底部固定输入框
- 消息右滑显示操作菜单

### MobileSidebar (Drawer)
- 左滑呼出侧边栏
- Persona切换、Agent面板入口

### CollapsiblePanels
- Skill Panel改为可折叠抽屉
- Memory Panel改为可折叠抽屉

## 5. Technical Changes

### CSS
- `src/styles/mobile.css` — 媒体查询样式
- 现有组件添加 `className={cn('panel', isMobile && 'panel-mobile')}`

### Component Conditionally Render
```tsx
// App.tsx
{!isMobile && <Sidebar />}
{isMobile && <BottomTabNav />}

// ChatPanel
{isMobile ? <MobileChatPanel /> : <DesktopChatPanel />}
```

### Hooks
- `src/hooks/useMobile.ts` — `isMobile` / `isTablet` / `isDesktop`
- `src/hooks/useSwipeGesture.ts` — 手势检测

## 6. Priority

**Must have (V86)**:
- 响应式布局基础
- BottomTabNav
- 移动端聊天界面
- 侧边栏抽屉化
- 可折叠面板

**Nice to have (V87+)**:
- 手势导航
- 性能优化
- PWA支持

## 7. Constraints
- 不破坏桌面端体验
- 不重复代码，用条件渲染而非两套组件
- 浅色主题延续
