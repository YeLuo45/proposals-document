# PRJ-20260509-001 — PixelPal V58: 语音交互升级

## 概述
语音输入（STT）+ 语音朗读（TTS）+ 情绪检测三大功能，让 PixelPal 真正成为"会说话"的 AI 伴侣。

## 功能

### P0 — 语音输入（STT）
**功能**：用户点击麦克风按钮，说出内容，AI 识别为文字并发送。

**技术方案**：
- 使用浏览器原生 `SpeechRecognition` API（Chrome/Edge 支持）
- 备用：`webkitSpeechRecognition`（Safari）
- 实时显示识别文本，支持中断重说
- 按住说话 / 点击开始说话 两种模式可选

**UI**：
- ChatPanel 工具栏增加 🎤 麦克风图标
- 识别中显示波形或动画
- 识别完成自动填入输入框

### P1 — 语音朗读（TTS）
**功能**：AI 回复支持点击播放，用 TTS 朗读回复内容。

**技术方案**：
- 使用浏览器原生 `SpeechSynthesis` API
- 优先使用 Web Speech API（无需外部依赖）
- 支持暂停/停止/语速调节

**UI**：
- AI 消息气泡右下角增加 🔊 播放按钮
- 播放中按钮变为 ⏸ 暂停
- Settings 可调节语速（0.8x / 1x / 1.2x）

### P2 — 情绪检测（进阶）
**功能**：根据用户语音语速/音调/停顿判断情绪状态，触发不同的 Persona 响应。

**技术方案**：
- 在 SpeechRecognition 的 `onspeechend` 事件中分析：
  - 语速（words per minute）
  - 音高变化（pitch analysis via AudioContext）
  - 停顿频率
- 情绪分类：平静 / 兴奋 / 焦虑 / 疲惫
- 情绪影响 EmotionCurve 更新
