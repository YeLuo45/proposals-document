## 语义说明

- **Project（项目）** = 代码仓/产品线，长期存在；名称初始化后不可修改
- **Proposal（提案）** = 项目的一次开发任务，1:N 挂载在项目下
- **CSV 为持久化结构化数据**，提案系统 Web 应用读写 CSV
- **`project_proposal_mapping.csv`** 由 CSV 生成器自动维护
