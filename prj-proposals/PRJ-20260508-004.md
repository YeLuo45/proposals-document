# PRJ-20260508-004 — PixelPal V57: 记忆自动归档

## 概述
每周日自动总结本周对话生成摘要，写入 Memory 面板。超过 30 天的旧消息可归档或清理。

## 功能

### P0 — 周自动摘要
**触发时机**：每周日 24:00 触发（或用户手动点击"生成周报"）

**摘要生成流程**：
1. 从 IndexedDB 读取本周所有消息（按 timestamp 筛选）
2. 调用 AI 总结（用 MiniMax Chat API 或直接复用 taskPlanner 的 summarizer）
3. 生成结构化摘要：{week, summary, topics[], actionItems[]}
4. 写入 Memory 面板（memoryStorage.addMemory 或新建 store）

**UI**：
- Memory 面板新增"周报"tab 或筛选器
- 显示历史周报列表（按周分组）
- 点击展开查看详情

### P1 — 旧消息管理
**功能**：超过 30 天的消息可选择归档或清理

**交互**：
- 设置中新增"消息保留天数"（默认 30 天）
- 超过期限的消息自动归档到"历史消息"store（不删除，仅移出活跃库）
- 用户可手动清理或导出历史消息
