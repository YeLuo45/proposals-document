## Context

V4 实现了模型选择器和模板库。V5 深化 A 方向：用户偏好记忆（记住上次选择的模型）+ 模型使用统计（每个模型用了多少次）。

## Requirements

### R1: 用户偏好记忆
通过 Zustand persist 记住用户上次选择的模型：
- `lastSelectedModel: { image: 'image-01', music: 'music-2.6', tts: 'speech-01' }`
- 页面加载时自动恢复上次选择的模型
- 偏好跟随 store 自动持久化

### R2: 模型使用统计
在 store 中增加 `modelUsage: { [modelId]: count }`：
- 每次生成调用成功后 increment
- 在"我的"页面显示各模型使用次数排行榜

### R3: 使用统计 UI
在"我的"页面增加模型使用统计展示：
- 各模型调用次数柱状图或数字列表
- 格式：`image-01: 12次 | image-02: 3次`

### R4: 模型偏好自动填充
生成页加载时：
1. 读取 `lastSelectedModel` 恢复模型选择
2. 读取 `modelUsage` 显示"最常用"
