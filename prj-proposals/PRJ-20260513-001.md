## 背景

boss提出两个问题：
1. "Create New Agent"弹窗关闭不了，没有下一步
2. 人格agent需要具备soul.md、user.md、memory.md三个文件

---

## P0 - Bug修复

### 问题描述
AgentCreationWizard组件接收了`open` prop（line 1800: `open={agentBuilderOpen}`），但组件定义中**没有声明和使用这个prop**，导致弹窗始终渲染，无法通过外部状态关闭。

### 修复方案
1. AgentCreationWizard接收`open: boolean` prop
2. 组件外层用条件渲染：`open ? <Paper>...</Paper> : null`
3. 当`open=false`时完全不渲染

## P1 - 新功能：人格文件支持

### 功能描述
每个人格(Persona)需要三个文件支持完整的人格系统：

| 文件 | 用途 | 内容示例 |
|------|------|---------|
| soul.md | 人格设定 | 性格描述、语气、价值观、行为准则 |
| user.md | 用户偏好 | 记录用户喜欢的话题、沟通风格偏好 |
| memory.md | 聊天记忆 | 历史对话摘要、重要事件、关系进展 |

### 实现方案

#### 1. 扩展Persona接口
```typescript
interface Persona {
  // ...现有字段
  soul?: string;      // soul.md内容
  userProfile?: string; // user.md内容
  memory?: string;    // memory.md内容
}
```

#### 2. 新增文件路径约定
```
src/data/personas/{personaId}/
  soul.md
  user.md
  memory.md
```

#### 3. 存储服务扩展
- `personaStorage.ts`：支持soul/userProfile/memory字段的CRUD
- 默认人格预置三个文件内容

#### 4. UI入口
- PersonaDetail页面：显示/编辑soul/userProfile/memory
- 或新建PersonaFiles编辑组件
