# PRD: PixelPal V30 — Model自由输入 + 非聊天面板全宽

## 需求1: Model字段支持手动输入

**问题**：Settings 中 Model 下拉只能选预设值，但模型迭代快，需要自由输入。

**改动**：Settings.tsx 第1682-1704行，删除条件分支，始终用 TextField 替代 Select。

```tsx
// 改前：getAvailableModelsForProvider 有值时 Select，否则 TextField
// 改后：始终 TextField
<TextField
  label="Model Name"
  value={dialogModel.modelName || ''}
  onChange={(e) => setDialogModel({ ...dialogModel, modelName: e.target.value })}
  size="small"
  fullWidth
  placeholder="e.g., gpt-4o-mini, claude-3-5-sonnet"
/>
```

## 需求2: 非聊天面板全宽

**问题**：V27 只修了 ChatPanel，Memory/Calendar/Tasks 等仍有留白。

**改动**：
- `MemoryPanel.tsx`：根 Box 加 `width: '100%'`
- `Calendar.tsx`：根元素加 `width: '100%'`
- `Tasks.tsx`：根 DndContext 加 `width: '100%'`

## 验收标准

1. Model 字段始终可手动输入任何模型名
2. 记忆、日历、任务等面板占满内容区全宽
3. 聊天面板保持 V28 的全宽处理不变
