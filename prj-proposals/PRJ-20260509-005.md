## 1. 背景与目标

当前Agent执行任务时，每次executeTask都是独立上下文——没有记忆之前对话中积累的信息。用户每次都要重新解释背景。

**目标：** 引入会话级记忆上下文，让Agent能"记住"当前对话窗口内的关键信息，在任务分解和执行时自动引用。

---

## 2. 功能需求

### 2.1 记忆上下文存储（MessageHistoryMemory）

在`src/services/agent/`下新增`memory/`目录：

```
src/services/agent/memory/
  MemoryContext.ts     — 记忆上下文接口和基础类型
  messageHistoryMemory.ts — 基于现有MessageHistory的记忆实现
  memoryManager.ts     — 记忆管理器，单例
```

**MemoryContext接口：**
```typescript
interface MemoryEntry {
  id: string
  type: 'fact' | 'preference' | 'context' | 'task_result'
  content: string
  importance: 'high' | 'medium' | 'low'
  createdAt: number
  expiresAt?: number  // 可选TTL
}

interface MemoryContext {
  entries: MemoryEntry[]
  sessionId: string
  getRelevant(query: string, limit?: number): MemoryEntry[]
  add(entry: Omit<MemoryEntry, 'id' | 'createdAt'>): void
  clear(): void
}
```

### 2.2 MessageHistoryMemory实现

- 复用现有的`src/services/storage/messageHistory.ts`（IndexedDB存储）
- 读取最近N条消息（默认50条），提取关键信息构建记忆条目
- 过滤条件：保留包含事实陈述、用户偏好、任务结果的消息
- 格式：`[类型] 内容`

### 2.3 AgentExecutor集成记忆

修改`agentExecutor.ts`：

```typescript
// executeTask开始时
const context = memoryManager.getContext()
const relevantHistory = context.getRelevant(task.goal, 5)  // 取最相关的5条

// 构建LLM提示词时，在system prompt中注入：
// "当前对话记忆：\n" + relevantHistory.map(e => `[${e.type}] ${e.content}`).join('\n')
```

### 2.4 记忆自动提取

新增`src/services/agent/memory/memoryExtractor.ts`：

- 任务完成后，从执行结果中提取关键信息写入记忆
- 用户确认任务时，提取确认内容作为记忆
- 定期（每5分钟或每10条消息）从历史消息中抽取新记忆

### 2.5 UI：记忆状态指示

在`AgentPanel.tsx`或侧边栏显示当前记忆状态：
- 记忆条目数量
- 最近一条记忆预览
- "清空记忆"按钮

---

## 3. 非功能需求

- 记忆只在当前会话有效（刷新后清空，或可配置持久化）
- 记忆不影响执行性能（异步提取，不阻塞主流程）
- 兼容现有AgentExecutor和Plan系统

---

## 4. 验收标准

1. Agent执行任务时，LLM提示词中包含当前会话记忆
2. 用户可以在UI看到当前记忆条目数
3. "清空记忆"按钮可清除所有记忆
4. 任务完成后自动提取结果写入记忆
5. build通过：`npx vite build --mode production`
6. 无新增console.error

---

## 5. 技术方案

- 基于现有MessageHistory（IndexedDB）实现，无需新存储
- 记忆提取用简单规则（关键词匹配），暂不用LLM二次处理
- MemoryManager单例，在AgentPanel mount时初始化
