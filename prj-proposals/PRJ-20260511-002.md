# PRJ-20260511-002 — PixelPal V65: 情绪曲线接入语音情绪数据

## 概述
V63 实现了语音情绪检测，但数据只写入了 Zustand store 的 `emotionHistory`，没有写入 `emotionStorage.ts`（EmotionCurve 的数据源）。V65 将两条数据流打通：语音情绪数据同时写入 EmotionCurve 的 localStorage，曲线图表可以展示语音触发的情绪。

## 现状分析

### V63 语音情绪检测流程
1. `SpeechButton.tsx` — 调用 `detectEmotion(transcript, durationMs)` → 返回 `EmotionResult`
2. `ChatPanel.tsx` — `onEmotionDetected` 回调 → `setCurrentEmotion()` + `addEmotionEntry()` → Zustand store
3. `emotionDetector.ts` — `EmotionState = 'excited' | 'calm' | 'tense' | 'low_energy' | 'unknown'`

### EmotionCurve 读取流程
- `EmotionCurve.tsx` → `getEmotionLogs()` from `emotionStorage.ts` → localStorage key `pixelpal_emotion_logs`
- `EmotionLogEntry.source: 'text' | 'voice'` — storage 已经支持 voice source，但 V63 没有写入

### 类型映射问题
- `EmotionState`（emotionDetector）: `excited | calm | tense | low_energy | unknown`
- `TextEmotion`（emotionService）: `happy | calm | anxious | angry | sad | excited | exhausted | unknown`
- 需要映射：`emotionState → TextEmotion`，否则 EmotionCurve 无法正确显示

**映射关系：**
- `excited` → `excited` ✅
- `calm` → `calm` ✅
- `tense` → `anxious` ✅
- `low_energy` → `exhausted` ✅
- `unknown` → `unknown` ✅

## 功能

### P0 — 打通语音情绪 → EmotionCurve 数据流

**改动点：**

1. **emotionDetector.ts** — 新增 `mapEmotionStateToTextEmotion()` 函数：
   ```typescript
   export function mapEmotionStateToTextEmotion(state: EmotionState): TextEmotion {
     const map: Record<EmotionState, TextEmotion> = {
       excited: 'excited',
       calm: 'calm',
       tense: 'anxious',
       low_energy: 'exhausted',
       unknown: 'unknown',
     };
     return map[state];
   }
   ```

2. **emotionStorage.ts** — 新增 `addVoiceEmotionLog()` 函数（便捷包装）：
   ```typescript
   import { type EmotionState } from '../voice/emotionDetector';
   import { mapEmotionStateToTextEmotion } from './emotionService';
   
   export function addVoiceEmotionLog(emotionState: EmotionState, intensity: number, context: string): void {
     const entry: EmotionLogEntry = {
       id: crypto.randomUUID(),
       timestamp: Date.now(),
       emotion: mapEmotionStateToTextEmotion(emotionState),
       intensity, // 0-100
       context,
       source: 'voice',
     };
     addEmotionLog(entry);
   }
   ```
   注意：`intensity` 可以用 `confidence * 100` 换算

3. **ChatPanel.tsx** — 在 `onEmotionDetected` 回调中，在 `setCurrentEmotion()` 和 `addEmotionEntry()` 之后，额外调用 `addVoiceEmotionLog()`：
   ```typescript
   import { addVoiceEmotionLog } from '../../services/emotion/emotionStorage';
   
   // onEmotionDetected handler:
   addVoiceEmotionLog(result.emotion, result.confidence * 100, `语音:${transcript.slice(0, 30)}`);
   ```

### P1 — EmotionCurve 增加"语音"标签筛选（可选）
在 EmotionCurve 的 distribution 统计中，可以区分 text source 和 voice source 的情绪数据。但这不是必须的 — 只要数据写入了，图表自然会显示。
