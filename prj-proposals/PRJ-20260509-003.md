# PRJ-20260509-003 — PixelPal V60: 插件执行（AI触发插件）

## 概述
让 AI 能够识别用户意图 → 调用插件 action → 将结果返回给 AI → 生成自然语言回复。实现"插件被 AI 调用"的端到端闭环。

## 功能

### P0 — 插件 action 路由
**流程**：用户输入（如"北京天气"）→ AI 识别意图 → 调用 pluginRegistry.executeAction() → 结果返回 AI → AI 生成回复

**实现方式**：
在 `chatService.ts` 或 `useChat()` hook 中，处理 AI 回复前检查：
1. 用户消息是否匹配某个插件 action 的触发词（如"天气"、"计算"、"翻译"）
2. 如果匹配，调用 `pluginRegistry.executeAction(pluginId, actionId, params)` 获取结果
3. 将结果注入到 AI 的上下文中，让 AI 基于结果生成自然语言回复

**触发检测**：
- 简单方案：关键词匹配（如消息包含"天气"→调用 getWeather）
- 进阶方案：让 AI 自行判断是否需要调用插件（few-shot prompt）

### P1 — 插件结果注入
**实现**：
- 执行 action 后，将结果格式化为结构化文本（如 `{action: "getWeather", result: "北京：晴，25°C"}`）
- 将结构化结果插入消息历史（作为 system 或 tool message）
- AI 读取结果生成自然语言回复

**Prompt 设计**：
```
当你识别到用户请求可以由插件完成（天气/计算/翻译）时：
1. 先回复"正在查询..."（可选）
2. 调用对应 action
3. 基于结果回复用户
```

## 文件清单

修改:
- `src/services/plugins/pluginRegistry.ts` — 新增 `matchAction(text)` 方法，返回匹配的插件和参数
- `src/services/ai/chatService.ts` 或 `src/hooks/useChat.ts` — 插件 action 拦截和执行逻辑
- `src/services/plugins/presetPlugins.ts` — 确保 action 有明确的触发关键词
