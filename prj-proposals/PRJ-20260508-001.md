# PRJ-20260508-001 — PixelPal V54: 自主 Agent 规划

## 概述
让 PixelPal 从"被动问答"升级为"主动规划助手"——用户设定目标，AI 自动拆解为任务并录入 Tasks 面板持续追踪。

## 需求池

### P0 — 目标拆解 & 任务录入
**功能**：用户说"帮我规划一周"/"我想学英语"/"准备面试"，AI 自动解析目标 → 生成任务列表 → 批量写入 Tasks 面板

**交互流程**：
1. 用户在 Chat 输入目标描述
2. AI 识别为 Goal-Oriented（`isGoalOriented()` 已有）
3. AI 调用 `createTaskFromGoal()` 解析任务
4. 弹确认框展示任务列表，用户确认后批量创建

**实现要点**：
- `isGoalOriented()` 已存在（`src/services/agent/taskPlanner.ts`）
- `createTaskFromGoal()` 已存在，接收 goal string 返回 Task[]
- Tasks 面板已有 CRUD，支持 `taskStore.addTask()`
- 确认框用 MUI Dialog，任务列表可编辑（勾选/删除/调整顺序）

**文件**：
- `src/components/ChatPanel/ChatPanel.tsx` — 检测 goal 消息，触发确认框
- `src/components/Tasks/Tasks.tsx` — 批量插入任务入口
- `src/services/agent/taskPlanner.ts` — 已有 isGoalOriented + createTaskFromGoal

---

### P1 — 场景触发进化（条件链）
**功能**：SceneScheduler 支持"条件A → 自动执行B → 触发C"链式触发

**交互流程**：
1. 管理员在 SceneEditor 中配置：触发条件 + 执行动作 + 后续条件
2. 满足触发条件时，自动执行对应 Action
3. Action 执行完后检查后续条件，满足则继续链

**实现要点**：
- SceneConfig 已有 `trigger: { type, params }` 和 `actions: Action[]`
- 新增 `chain: { nextCondition, nextActions }` 字段
- `checkKeywordTrigger()` 已支持关键词触发
- 扩展为 `checkSceneChain()` 支持条件链判断

**文件**：
- `src/utils/sceneScheduler.ts` — 新增 chain 逻辑
- `src/components/Scenes/SceneEditorDialog.tsx` — 条件链配置 UI
- `src/types/scene.ts` — 新增 ChainConfig 类型

---

### P2 — 多人格分工
**功能**：用户指定不同 persona 处理不同任务类型（规划找"老师"、闲聊找"朋友"、情绪支持找"恋人"）

**交互流程**：
1. 用户输入 `/assign [任务类型] to [persona]` 或通过 Settings 配置"任务类型→人格"映射表
2. 不同类型的任务自动路由到对应 persona 响应
3. Tasks 面板的任务可标记类型（学习/工作/生活）

**实现要点**：
- `getAllPersonas()` 和 `getPersonaSystemPrompt()` 已存在
- 新增 `PersonaRouter`：根据任务类型自动选择 persona
- Settings 增加"人格分工"配置面板（taskType → personaId 映射表）
- Tasks 面板任务增加 type 字段（学习/工作/生活/社交）

**文件**：
- `src/services/persona/personaRouter.ts` — 新建，路由逻辑
- `src/components/Settings/Settings.tsx` — 分工配置 UI
- `src/components/Tasks/Tasks.tsx` — 任务 type 字段
- `src/store/taskStore.ts` — type 字段支持
