# PRJ-20260512-002: PixelPal Skill Chaining V79

## 1. Concept & Vision

Skill Chaining 允许用户将多个 Skill 按条件编排成链式执行流程。一个 Chain 由多个 Step 组成，每个 Step 调用一个 Skill，上一个 Step 的输出可作为下一个 Step 的输入。适用于复杂多步任务（如：查天气 → 判断是否出行 → 生成日程）。

## 2. Design Language

沿用 Skill Marketplace 的浅色主题，与 V78 保持一致。

## 4. Features & Interactions

### 4.1 Chain Definition

```typescript
interface ChainStep {
  id: string;
  skillId: string;
  /** Condition to execute this step: 'always' | 'if:{expr}' */
  condition: string;
  /** JSON template for skill input, supports {{variable}} interpolation */
  inputTemplate: Record<string, string>;
  /** Key to store this step's result */
  outputKey: string;
}

interface ChainDefinition {
  id: string;
  name: string;
  description: string;
  triggerKeywords: string[];  // chat keywords that activate this chain
  steps: ChainStep[];
  enabled: boolean;
}
```

### 4.2 Variable Interpolation

- `{{step1_result}}` — reference previous step output
- `{{context.city}}` — reference execution context fields
- `{{triggerMessage}}` — the original user message

### 4.3 Condition Syntax

- `always` — step always runs
- `if:{expr}` — step runs only if expression is truthy
  - Examples: `if:step1_result contains "晴天"`, `if:step2_result > 0`

### 4.4 Chain Execution

1. User types message matching chain trigger keyword
2. Chain engine resolves all variable interpolations
3. Steps execute sequentially, each feeding into next
4. Final result posted to chat
5. Show step-by-step progress in chat (like skill showSteps)

### 4.5 Chat Integration

- Chains triggered by keyword prefix `#` in chat
- Example: `#trip 北京 5月20日` → triggers trip planning chain
- Chain results rendered as styled card in chat

### 6.4 Chain Engine Logic

```typescript
// Pseudocode
async function executeChain(chain: ChainDefinition, context: SkillExecutionContext) {
  const vars = { context: context.metadata, triggerMessage: context.triggerMessage };
  const results: Record<string, unknown> = {};
  
  for (const step of chain.steps) {
    if (!evaluateCondition(step.condition, vars)) continue;
    
    const resolvedInput = resolveTemplate(step.inputTemplate, vars);
    const result = await skillRunner.execute(step.skillId, { ...context, parsedParams: resolvedInput });
    results[step.outputKey] = result.response;
    vars[step.outputKey] = result.response;
  }
  
  return results;
}
```
