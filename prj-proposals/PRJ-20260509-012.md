## 1. 背景与目标

V71实现了 `SceneAwarenessEngine`（场景感知），能检测时间场景和用户状态，但目前独立运行，未与Agent执行流程绑定。

**目标：** 将场景上下文（时间+用户状态）注入Agent执行上下文，让Agent在分解任务时能感知用户当前所处场景。

---

## 2. 现状分析

### 2.1 SceneAwarenessEngine（V71）
- `recordAction()` / `recordError()` — 更新用户状态
- `getSceneResponse()` — 获取场景响应
- 独立模块，不影响主流程

### 2.2 AgentExecutor（V64+V73）
- V73已集成 `emotionContextInjector`
- `decomposeGoal()` — LLM分解目标
- `executeTask()` — 执行任务

### 2.3 缺失环节
```
SceneAwarenessEngine → 场景上下文 → 未注入Agent
```

## 3. 功能设计

### 3.1 场景上下文类型

```typescript
// src/services/agent/types.ts 新增

export interface SceneContext {
  detected: boolean
  timeScene: TimeScene | null   // 'morning'|'work'|'afternoon'|'late_afternoon'|'evening'|'night'
  isWeekend: boolean
  userState: UserState | null    // 'active'|'idle'|'returning'|'struggling'|'deep_focus'
  sceneResponse: {
    type: 'suggest' | 'offer_help' | 'remind' | 'adapt' | 'none'
    message: string
    suggestedAction?: string
  } | null
  triggered: boolean
}
```

### 3.2 SceneContextInjector

```typescript
// src/services/agent/sceneContextInjector.ts

import { sceneAwarenessEngine, getTimeScene, isWeekend } from '../scene'
import type { UserState } from '../scene/userStateScene'
import type { SceneContext } from './types'

class SceneContextInjector {
  private currentContext: SceneContext = {
    detected: false,
    timeScene: null,
    isWeekend: false,
    userState: null,
    sceneResponse: null,
    triggered: false,
  }

  detectScene(): SceneContext {
    const timeScene = getTimeScene()
    const userStateSignal = sceneAwarenessEngine.getUserState()
    const response = sceneAwarenessEngine.getSceneResponse()

    this.currentContext = {
      detected: true,
      timeScene,
      isWeekend: isWeekend(),
      userState: userStateSignal.state,
      sceneResponse: response
        ? { type: response.action.type, message: response.action.message, suggestedAction: response.action.suggestedAction }
        : null,
      triggered: false,
    }

    return this.currentContext
  }

  getContext(): SceneContext {
    return this.currentContext
  }

  markTriggered(): void {
    this.currentContext.triggered = true
  }

  formatForPrompt(): string {
    const ctx = this.currentContext
    if (!ctx.detected) return ''

    let prompt = `\n[用户场景状态]\n`

    // 时间场景
    if (ctx.timeScene) {
      const timeLabels: Record<string, string> = {
        morning: '早晨 (6:00-9:00)',
        work: '工作时间 (9:00-12:00)',
        afternoon: '午间 (12:00-14:00)',
        late_afternoon: '下午 (14:00-18:00)',
        evening: '晚间 (18:00-22:00)',
        night: '深夜 (22:00-6:00)',
      }
      prompt += `时间: ${timeLabels[ctx.timeScene] || ctx.timeScene}\n`
      prompt += `周末: ${ctx.isWeekend ? '是' : '否'}\n`
    }

    // 用户状态
    if (ctx.userState) {
      const stateLabels: Record<string, string> = {
        active: '活跃（正在操作）',
        idle: '闲置（长时间无操作）',
        returning: '刚回来（从闲置恢复）',
        struggling: '遇到困难（操作多次失败）',
        deep_focus: '深度专注',
      }
      prompt += `用户状态: ${stateLabels[ctx.userState] || ctx.userState}\n`
    }

    // 场景响应建议
    if (ctx.sceneResponse && ctx.sceneResponse.type !== 'none') {
      prompt += `场景建议: ${ctx.sceneResponse.type}\n`
      prompt += `建议消息: "${ctx.sceneResponse.message}"\n`
      if (ctx.sceneResponse.suggestedAction && ctx.sceneResponse.suggestedAction !== 'none') {
        prompt += `建议行动: ${ctx.sceneResponse.suggestedAction}\n`
      }
    }

    return prompt
  }
}

export const sceneContextInjector = new SceneContextInjector()
```

### 3.3 AgentExecutor集成

修改 `src/services/agent/agentExecutor.ts`：

在 `decomposeGoal()` 的提示词中，添加场景上下文（与情感上下文类似位置）：

```typescript
// 现有：
const memoryContext = memoryManager.getContextForPrompt?.() || ''
const emotionContext = emotionContextInjector.formatForPrompt()
// 新增：
const sceneContext = sceneContextInjector.formatForPrompt()

const prompt = `
任务: ${task.goal}
${memoryContext ? `记忆上下文:\n${memoryContext}` : ''}
${emotionContext}
${sceneContext}
请分解任务为具体执行步骤。
`
```

在 `executeTask()` 完成后，检查场景响应：

```typescript
// 在sendEmotionResponse之后添加：
const sceneCtx = sceneContextInjector.getContext()
if (sceneCtx.sceneResponse && !sceneCtx.triggered && sceneCtx.sceneResponse.type !== 'none') {
  const adapter = getCurrentPlatformAdapter()
  if (adapter) {
    try {
      await adapter.sendMessage(sceneCtx.sceneResponse.message)
      sceneContextInjector.markTriggered()
    } catch (e) {
      console.warn('[AgentExecutor] 场景响应发送失败:', e)
    }
  }
}
```

### 3.4 UI层集成（可选）

const handleUserAction = (action: string) => {

  sceneAwarenessEngine.recordError()

## 4. 非功能需求

- 场景上下文仅影响LLM提示词，不阻塞执行流程

- 与情感上下文独立，互不干扰
- recordAction/recordError由UI层调用（本次只预留接口）
