## 1. 概念与愿景

在 V27 多人讨论的基础上，增加实时情绪追踪和可视化。讨论过程中实时显示各 persona 的情绪状态，以动态进度条和颜色变化呈现在消息气泡上。讨论结束后生成情绪摘要报告。

---

## 2. 功能点

### P0（必须）
- [ ] 实时情绪进度条 — 每条消息气泡顶部显示情绪强度条（0-100%），颜色随情绪变化
- [ ] 情绪颜色气泡 — 消息背景渐变随情绪变化（愤怒=红，开心=黄，平静=蓝...）
- [ ] 情绪历史折线图 — 讨论过程中各 persona 情绪随时间变化的 mini 折线图

### P1（应该）
- [ ] 情绪摘要卡片 — 讨论结束后展示：参与 persona 情绪分布饼图 + 平均情绪值
- [ ] 情绪突变标记 — 当情绪波动超过阈值时消息气泡加特殊边框闪烁

---

## 3. 技术方案

### 复用现有
- `emotionDetector.ts` — `detectEmotion(text)` → emotion string
- `emotionColors` mapping
- 消息气泡 UI 在 `MultiPersonaCollaboration.tsx`

### 情绪进度条
- 每条消息增加 `emotionScore: number` (0-100)
- 气泡顶部加 `<LinearProgress>` 显示情绪强度
- 使用 emotion → color 映射决定进度条颜色

### 情绪折线图
- 使用 `<canvas>` 或简单 SVG 绘制
- 记录每个 persona 每条消息的情绪分
- 随消息增加实时更新
