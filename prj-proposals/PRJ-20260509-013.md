## 1. 背景与目标

V71实现了 `SceneAwarenessEngine` 的 `recordAction()` / `recordError()` 接口，但UI层从未调用它们，导致场景感知引擎始终认为用户是 `active` 状态。

V74将场景上下文注入了AgentExecutor，但 `userState` 永远检测不到 `idle` / `returning` / `struggling`。

**目标：** 在ChatPanel等UI组件中集成sceneAwarenessEngine，让用户操作和错误能正确触发场景状态变化。

## 2. 功能设计

### 2.1 创建useSceneAwareness Hook

```typescript
// src/hooks/useSceneAwareness.ts

import { useEffect, useCallback } from 'react'
import { sceneAwarenessEngine } from '../services/scene'

export function useSceneAwareness() {
  // 页面加载时初始化为active
  useEffect(() => {
    sceneAwarenessEngine.recordAction('page_load')
  }, [])

  // 记录用户操作
  const recordAction = useCallback((action: string) => {
    sceneAwarenessEngine.recordAction(action)
  }, [])

  // 记录错误
  const recordError = useCallback((errorInfo?: string) => {
    sceneAwarenessEngine.recordError()
  }, [])

  // 获取当前场景响应（用于UI提示）
  const getSceneResponse = useCallback(() => {
    return sceneAwarenessEngine.getSceneResponse()
  }, [])

  // 获取用户状态
  const getUserState = useCallback(() => {
    return sceneAwarenessEngine.getUserState()
  }, [])

  return {
    recordAction,
    recordError,
    getSceneResponse,
    getUserState,
  }
}
```

### 2.2 ChatPanel集成

修改 `src/components/ChatPanel/ChatPanel.tsx`：

```typescript
import { useSceneAwareness } from '../../hooks/useSceneAwareness'

// 在组件内：
const { recordAction, recordError } = useSceneAwareness()

// 发送消息时
const handleSend = async (message: string) => {
  recordAction('send_message')  // 记录用户活跃
  // ... 原有逻辑
}

// Agent响应时
const handleAgentResponse = () => {
  recordAction('receive_agent_response')
}

// 发送失败时
const handleSendError = () => {
  recordError('send_failed')
}
```

### 2.3 场景响应提示UI

在 `ChatPanel.tsx` 或新建 `SceneResponseToast.tsx`：

```typescript
// 显示场景响应的Toast提示
const SceneResponseToast = ({ response }: { response: SceneResponse | null }) => {
  if (!response || response.action.type === 'none') return null

  return (
    <div className="scene-response-toast">
      <span>{response.action.message}</span>
    </div>
  )
}
```

### 2.4 AgentPanel集成

```typescript
import { useSceneAwareness } from '../../hooks/useSceneAwareness'

// 在AgentPanel组件内：
const { recordAction, recordError } = useSceneAwareness()

// 任务开始时
const handleTaskStart = () => {
  recordAction('agent_task_start')
}

// 任务完成时
const handleTaskComplete = () => {
  recordAction('agent_task_complete')
}

// 任务失败时
const handleTaskError = () => {
  recordError('agent_task_failed')
}
```

### 2.5 App.tsx全局集成（可选）

在根组件添加全局的idle检测：

```typescript
useEffect(() => {
  // 全局鼠标/键盘活动检测
  const handleActivity = () => {
    sceneAwarenessEngine.recordAction('global_activity')
  }

  window.addEventListener('mousemove', handleActivity, { throttle: 60000 }) // 每分钟最多1次
  window.addEventListener('keydown', handleActivity, { throttle: 60000 })

  return () => {
    window.removeEventListener('mousemove', handleActivity)
    window.removeEventListener('keydown', handleActivity)
  }
}, [])
```

## 3. 非功能需求

- `recordAction` 频繁调用时有内部节流
- 不上传任何隐私数据
- Toast提示需要用户确认才显示下一条
- 全局事件监听使用节流避免性能问题

---

## 4. 验收标准

1. `npx vite build --mode production` 通过
2. `useSceneAwareness` hook 正确导出 recordAction/recordError/getSceneResponse/getUserState
3. ChatPanel 集成 recordAction（发送消息时）
4. AgentPanel 集成 recordAction/recordError（任务开始/完成/失败）
5. 场景响应Toast组件可显示
6. 无新增 console.error
