# PRD: V113 离线优先架构（Thunderbolt风格SQLite存储）

## 概述

基于 Thunderbolt 架构的离线优先理念，为 pixel-pal-web 引入 **drizzle-orm/wa-sqlite** 本地SQLite存储，替代当前散装的 localStorage/IndexedDB 调用，实现统一的数据访问层。

## 现状问题

- 聊天记录/Memory/Settings 使用散装 localStorage + IndexedDB
- 浏览器关闭后数据访问慢（无本地缓存）
- 无统一 ORM，数据迁移困难

## 目标

1. 引入 drizzle-orm + wa-sqlite（浏览器SQLite）
2. 定义统一 schema：messages, memories, settings, personas, skills
3. 替换 localStorage 调用为 SQLite 查询
4. 保留 IndexedDB 作为向后兼容过渡层

## 实现步骤

### 1. 依赖安装
```bash
npm install drizzle-orm drizzle-orm/wa-sqlite idb
npm install -D drizzle-kit @types/better-sqlite3
```

### 2. Schema 定义
创建 `src/db/schema.ts`：
```typescript
import { sqliteTable, text, integer, real } from 'drizzle-orm/sqlite-core';

export const messages = sqliteTable('messages', {
  id: text('id').primaryKey(),
  role: text('role'), // 'user' | 'assistant'
  content: text('content'),
  channel: text('channel'), // 'web' | 'telegram' | ...
  timestamp: integer('timestamp', { mode: 'timestamp' }),
  metadata: text('metadata'), // JSON string
});

export const memories = sqliteTable('memories', {
  id: text('id').primaryKey(),
  content: text('content'),
  embedding: text('embedding'), // vector as JSON string
  tags: text('tags'),
  createdAt: integer('created_at', { mode: 'timestamp' }),
});

export const settings = sqliteTable('settings', {
  key: text('key').primaryKey(),
  value: text('value'),
});

export const personas = sqliteTable('personas', {
  id: text('id').primaryKey(),
  name: text('name'),
  avatar: text('avatar'),
  // ... other persona fields
});
```

### 3. DB 初始化
创建 `src/db/index.ts`：
```typescript
import { drizzle } from 'drizzle-orm/wa-sqlite';
import { open } from 'wa-sqlite';
import * as schema from './schema';

let db: ReturnType<typeof drizzle> | null = null;

export async function initDB() {
  const sqlite = await open({ filename: 'pixelpal.db' });
  db = drizzle(sqlite, { schema });
  return db;
}

export function getDB() {
  if (!db) throw new Error('DB not initialized');
  return db;
}
```

### 4. 数据迁移现有存储

创建 `src/db/migration.ts`：
- 从 localStorage 读取现有数据
- 写入 SQLite
- 标记迁移完成

### 5. 替换 ChatPanel 消息存储
修改 `ChatPanel.tsx` 使用 SQLite 而非 localStorage。

### 6. 替换 Memory 存储
修改 `MemoryPanel.tsx` 使用 SQLite 而非现有 IndexedDB。
