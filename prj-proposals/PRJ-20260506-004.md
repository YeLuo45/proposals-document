## 背景与问题
PixelPal 的 PersonaSelector（人格切换器）已在 V24 恢复到 Sidebar 顶。但当前只显示人格头像和名称，**亲密度（Intimacy）完全没有可视化**。

系统已有完整的亲密度计算逻辑：
- `getIntimacyLevel(value)` → 陌生人/熟人/朋友/挚友/灵魂伴侣
- `getIntimacyColor(value)` → 对应颜色
- `personaIntimacy` store 字段
- Collapsed 模式下亲密度 ≥61 时头像有金色光晕

但非折叠模式下没有任何亲密度指示器。

## 需求描述

### 核心功能

#### 1. 亲密度进度条（PersonaSelector 展开模式）
在当前人格按钮下方，**头像旁边或下方**添加：
- 线性进度条（`LinearProgress` 或自定义），显示 0-100 亲密度值
- 进度条颜色使用 `getIntimacyColor(intimacy)` 对应颜色
- 旁边显示等级文字：`getIntimacyLevel(intimacy)`（如 "朋友" / "挚友"）
- 进度条宽度与按钮对齐

#### 2. 亲密度菜单项（Dropdown Menu）
在 PersonaSelector 的下拉菜单中：
- 当前人格行显示亲密度进度条 + 等级文字
- 其他人格行显示当前亲密度 + 等级

#### 3. 折叠模式增强（Collapsed Mode）
当前已有关闭（≥61 金色光晕），保持不变。可选增强：
- Tooltip 显示亲密度数值和等级

#### 4. 亲密度徽章（Card 显示）
当亲密度达到特定里程碑时，显示徽章：
- 熟人（21+）：🌱
- 朋友（41+）：🤝
- 挚友（61+）：💎（已有光晕效果）
- 灵魂伴侣（81+）：💜

#### 5. 亲密度变化动画
- 亲密度增加时，进度条有平滑过渡动画
- 使用 MUI `keyframes` 或 CSS transition
