# PRD: PixelPal V92 — Multimodal

## 1. Concept & Vision

PixelPal新增**图像理解**和**语音交互**两大模态。用户可以发送图片给PixelPal分析，也可以用语音对话。核心：让交互更自然、更接近人类沟通方式。

## 2. Core Features

### 图像理解
- 用户发送图片，PixelPal分析并回答
- 支持截图、照片、图表
- 图片内文字识别（OCR）
- 多图分析对比
- 图片生成描述（caption）

### 语音交互
- 语音输入：麦克风图标，点击说话
- 语音输出：PixelPal回复可转为语音
- 语音识别（STT）：语音→文字
- 语音合成（TTS）：文字→语音
- 语音情感分析：检测用户情绪调整回复

### 多模态融合
- 图片+文字混合输入
- 语音+图片同时对话
- 跨模态检索（说"找那张有猫的图片"）

## 3. Technical Approach

### Image Understanding
- 使用V81的Provider系统调用视觉模型
- MiniMax Vision / GPT-4 Vision / Gemini Pro Vision
- 降级策略：视觉模型不可用时返回"图片分析暂不可用"

### Speech (STT/TTS)
- **STT**: Web Speech API / Whisper API
- **TTS**: Web Speech API / MiniMax TTS
- 离线降级：Web Speech API作为备选

### Architecture
```
用户发送图片 → ImageProcessor → Provider.vision() → PixelPal回复
用户语音输入 → STT → 文字 → Agent处理 → TTS → 语音回复
```

## 5. Data Model

```typescript
interface VoiceMessage {
  id: string;
  type: 'voice_input' | 'voice_output';
  text: string;
  audioUrl?: string;
  duration?: number; // seconds
  language?: string;
}

interface ImageMessage {
  id: string;
  type: 'image';
  imageUrl: string;
  caption?: string;
  analysisResult?: string;
  detectedText?: string;
}

interface MultimodalInput {
  text?: string;
  images?: File[];
  voice?: Blob;
}
```
