## Context

ai-creator-h5 当前使用散装 localStorage 调用管理状态，参考 thunderbolt-design 的架构理念，引入 Zustand 统一状态管理 + 增强离线缓存能力。

## Requirements

### R1: 引入 Zustand 状态管理
```javascript
// src/store/useStore.js — 创建 zustand store
// State: apiKey, groupId, history[], theme, isOffline
// Actions: setApiKey, setGroupId, addHistory, setTheme, setOffline
```

### R2: 统一 localStorage 操作
原来散装的 `localStorage.getItem/setItem` 调用全部迁移到 store 的 persist middleware。

### R3: 离线缓存增强
- 生成结果（图片/音乐/语音 base64）缓存到 localStorage
- 离线状态检测：`navigator.onLine` + `online`/`offline` 事件
- 离线时显示全局离线状态栏

### R4: 构建验证
`npm run build` 必须通过。
