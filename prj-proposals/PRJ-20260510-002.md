# PRJ-20260510-002 — PixelPal V63: 语音情绪检测

## 概述
V58 已实现语音输入（STT）和文本情绪检测。V63 将语音特征（语速/停顿时长）接入情绪检测 — 用户说话后检测其情绪状态并展示。

## 现状分析
- `src/services/voice/emotionDetector.ts` — 已有基于语速的情绪检测逻辑（excited/calm/tense/low_energy），但从未被调用
- `src/hooks/useSpeechRecognition.ts` — 语音识别 hook，不记录语音时长
- `src/components/ChatInput/SpeechButton.tsx` — 麦克风按钮，识别完成后通过 `onTranscriptChange` 传递文字
- `src/services/emotion/emotionService.ts` — 文本情绪检测，source 字段支持 'voice'

## 功能

### P0 — 语音情绪检测集成
**改动点**：

1. **useSpeechRecognition hook** — 新增 `startTime` ref，`startListening` 时记录，识别完成时计算 duration。Hook 返回 `{ transcript, durationMs, ... }`

2. **SpeechButton** — `onTranscriptChange` 回调中，当 `transcript` 非空时，调用 `detectEmotion(transcript, durationMs)`，将结果通过新 prop `onEmotionDetected?: (result: EmotionResult) => void` 传递给父组件

3. **ChatInput/ChatInput.tsx** — 接收 `onEmotionDetected`，检测到情绪后显示临时 toast/banner（3秒自动消失），内容如"😊 检测到兴奋情绪"

4. **emotionDetector** — `detectEmotion()` 结果写入 `emotionService` 日志（`EmotionLogEntry`，source='voice'）

### P1 — 情绪展示增强
- 在 ChatInput 区域底部显示当前检测到的情绪标签（如"😰 紧张"），停留 5 秒后消失
- 情绪影响伴侣表情：检测到负面情绪（tense/low_energy）时，伴侣反应更温柔
