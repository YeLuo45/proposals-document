# API Proposal: P-20260529-144 — NarrativeTensionWaveform API Extensions

## 1. Concept & Vision

Extends the V260 NarrativeTensionWaveform engine with enhanced waveform analysis capabilities for novel narrative tension tracking and visualization. Provides richer tension patterns, waveform comparison, and prediction features.

Core value: From "tension tracking" to "tension intelligence" with predictive capabilities.

## 2. Design Sources

- V260 NarrativeTensionWaveform base implementation
- thunderbolt pipeline: event pattern analysis
- generic-agent: goal pursuit with milestone tracking

## 3. Function Modules

### 3.1 TensionPatternMatcher (tension pattern matching)
- Pattern recognition across waveform sequences
- Match against known narrative tension archetypes (3-act structure, hero's journey, etc.)
- Pattern similarity scoring

### 3.2 TensionPredictor (tension prediction)
- Predict future tension levels based on historical waveform
- Identify likely peak/valley positions
- Alert for tension imbalances

### 3.3 WaveformComparator (waveform comparison)
- Compare two narrative waveforms
- Compute similarity index
- Identify divergent sections

### 3.4 TensionArchetypeLibrary (archetype library)
- Predefined tension archetypes
- 3-act structure template
- Hero's journey template
- Mystery structure template
- Romance structure template

### 4.2 Data Models
```typescript
type TensionPattern = {
  patternId: string
  patternName: string
  archetype: "three-act" | "heros-journey" | "mystery" | "romance" | "custom"
  expectedPhases: TensionPhase[]
  peakPositions: number[]  // relative positions 0-100
  valleyPositions: number[]
}

type TensionPrediction = {
  predictedChapter: number
  predictedPosition: number
  confidence: number  // 0-100
  predictedPhase: TensionPhase
  reasoning: string
}

type WaveformComparison = {
  similarityScore: number  // 0-100
  divergentChapters: number[]
  commonPeaks: number
  commonValleys: number
}
```

## 5. API Surface

### 5.1 TensionPatternMatcher
- `matchPattern(state: TensionWaveformState, pattern: TensionPattern): number` — Returns match score 0-100
- `findPatternInWaveform(state: TensionWaveformState): TensionPattern | null`
- `getPatternDeviation(state: TensionWaveformState, pattern: TensionPattern): number[]` — Returns chapter deviations

### 5.2 TensionPredictor
- `predictNextTension(state: TensionWaveformState): TensionPrediction`
- `predictTensionAt(state: TensionWaveformState, chapter: number): number` — Returns predicted level
- `detectTensionImbalance(state: TensionWaveformState): string[]` — Returns warning messages

### 5.3 WaveformComparator
- `compareWaveforms(state1: TensionWaveformState, state2: TensionWaveformState): WaveformComparison`
- `computeSimilarityIndex(points1: TensionDataPoint[], points2: TensionDataPoint[]): number`

### 5.4 TensionArchetypeLibrary
- `getThreeActStructure(): TensionPattern`
- `getHerosJourneyPattern(): TensionPattern`
- `getMysteryPattern(): TensionPattern`
- `getRomancePattern(): TensionPattern`
