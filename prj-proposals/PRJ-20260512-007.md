# PRD: PixelPal V84 — Multi-Agent Deepening

## 1. Concept & Vision

深化V83 Multi-Agent系统，聚焦**Orchestrator智能任务分解**和**Critic改进反馈循环**。让多Agent协作从演示级别进化到真正能处理复杂任务的实用级别。

## 2. Core Features

### Orchestrator Enhanced
- **智能任务分解**: 输入复杂目标，自动分解为可执行的子任务树
- **依赖分析**: 自动识别任务间依赖关系，生成执行拓扑
- **动态调整**: 根据执行结果动态调整后续任务

### Critic Feedback Loop
- **结果审查**: Executor输出后，Critic立即审查
- **改进建议**: 生成具体可操作的改进意见
- **自动重试**: 根据Critic反馈自动重新执行（可配置）

### Demo场景增强
- 预设3个复杂任务演示（研究报告、代码开发、旅行规划）
- 实时显示任务分解、执行、审查的完整流程

## 3. Data Model

```typescript
interface DecomposedTask extends Task {
  estimatedDuration?: number;
  priority: 'high' | 'medium' | 'low';
  requiredCapabilities: string[];
  suggestedAgent?: AgentRole;
}

interface CriticReview {
  taskId: string;
  score: number; // 0-10
  issues: string[];
  suggestions: string[];
  approved: boolean;
}

interface ExecutionResult {
  taskId: string;
  output: string;
  criticReview?: CriticReview;
  retryCount: number;
  timestamp: number;
}
```

## 4. UI Changes

### OrchestratorPanel (增强MultiAgentPanel)
- 显示当前任务分解树
- 每个子任务显示：状态 + 负责Agent + Critic评分
- 点击任务展开：查看详细输入/输出

### CriticBadge
- Agent消息旁显示Critic评分badge
- 颜色：green(8-10) / yellow(5-7) / red(0-4)

### RetryButton
- 任务失败时显示"Request Critic Review"按钮
- 点击后触发Critic重新审查

## 5. Technical Approach

### Orchestrator增强
- `src/services/agents/Orchestrator.ts` — 智能任务分解
  - keyword extraction → task template matching → dependency analysis
- `src/services/agents/TaskDecomposer.ts` — 任务分解器

### Critic增强
- `src/services/agents/CriticEngine.ts` — 审查引擎
  - 评估输出质量、生成改进建议
- `CriticReview` UI组件

### Execution Loop
```
User Input → Orchestrator分解 → TaskScheduler安排 
→ Executor执行 → Critic审查 → 通过? 
  → Yes: 下一任务 
  → No: 改进建议 → Executor重试(最多3次)
→ 最终汇总 → 用户确认
```
