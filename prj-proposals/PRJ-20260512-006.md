# PRD: PixelPal V83 — Multi-Agent Collaboration System

## 1. Concept & Vision

PixelPal从单人AI助手进化为**多Agent协作平台**。用户可同时激活多个专业Agent（规划者、执行者、审查者、创意者等），它们在后台协作解决复杂任务，用户只需确认方向。核心体验：**你指挥，Agent团队执行**。

## 2. Core Architecture

### Agent类型
| Role | Icon | Specialty |
|------|------|-----------|
| Orchestrator | 🎯 | 理解用户意图，分解任务，协调其他Agent |
| Planner | 📋 | 制定执行计划，评估可行性 |
| Executor | ⚡ | 工具调用，执行具体操作 |
| Critic | 🔍 | 审查结果，提出改进建议 |
| Creative | 💡 | 头脑风暴，创意生成 |

### Agent间通信
- **Shared Context**: 所有Agent共享同一ConversationContext
- **Message Passing**: Agent之间通过事件总线传递消息
- **Task Board**: 任务分解后挂在Kanban风格的面板上

## 3. UI Components

### MultiAgentPanel (新侧边栏面板)
- Agent列表：当前激活的Agent及其状态（idle/running/thinking）
- 每个Agent显示：icon + name + 当前任务
- 点击Agent展开：查看其思考过程和输出
- 快速操作：添加/移除Agent，调整执行顺序

### TaskBoardModal
- 任务分解可视化：三列（待做/进行中/完成）
- 每个任务卡片：标题 + 负责Agent + 状态
- 拖拽调整任务状态

### AgentThoughtBubble
- Agent思考中显示：typing indicator + 当前步骤
- 支持折叠/展开查看详细思考链

## 4. Data Model

```typescript
interface Agent {
  id: string;
  role: 'orchestrator' | 'planner' | 'executor' | 'critic' | 'creative';
  name: string;
  icon: string;
  status: 'idle' | 'running' | 'thinking' | 'waiting';
  currentTask?: string;
  messages: AgentMessage[];
  capabilities: string[];
}

interface AgentMessage {
  id: string;
  agentId: string;
  type: 'thought' | 'action' | 'result' | 'critique';
  content: string;
  timestamp: number;
}

interface Task {
  id: string;
  title: string;
  description: string;
  status: 'pending' | 'in_progress' | 'completed';
  assignedAgent?: string;
  parentTaskId?: string;
  children: string[];
}
```

## 5. Interaction Flow

1. **用户输入复杂任务**（如"帮我调研RAG技术并写一份报告"）
2. **Orchestrator解析** → 分解为子任务列表
3. **TaskBoard显示** → 用户确认/调整任务分配
4. **多Agent并行执行** → Executor执行搜索，Critic审查，Creative提供创意
5. **结果汇总** → Orchestrator整合输出，用户确认

## 6. Technical Approach

- **EventEmitter**: Agent间事件总线（类似EventEmitter3）
- **AgentManager**: 统一管理Agent生命周期
- **TaskScheduler**: 任务调度（并行/串行/依赖）
- **ContextMerging**: 多Agent上下文合并策略
- **AgentRegistry**: 可插拔Agent注册表
