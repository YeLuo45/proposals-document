# PRD: PixelPal V93 — Collaboration

## 1. Concept & Vision

PixelPal新增**多人协作**功能。用户可以邀请他人加入对话、共同编辑Persona、分享Skill配置。核心：让PixelPal成为团队工具，而不只是个人助手。

## 2. Core Features

### 协作会话
- 创建协作房间（Room）
- 邀请链接分享
- 实时同步对话
- 参与者角色（ Owner / Editor / Viewer）

### 实时同步
- WebSocket连接（使用现有Collab系统）
- 操作转换（OT）或 CRDT 算法
- 离线消息队列
- 冲突解决

### 协作Persona
- 共同编辑Persona配置
- 版本历史（谁改了什么）
- 权限控制（可编辑/只读）

### 协作Skill
- 分享Skill配置给别人
- Skill模板市场
- 协作Skill使用统计

## 3. Data Model

```typescript
interface CollabRoom {
  id: string;
  name: string;
  ownerId: string;
  participants: Participant[];
  settings: RoomSettings;
  createdAt: number;
}

interface Participant {
  id: string;
  userId: string;
  name: string;
  role: 'owner' | 'editor' | 'viewer';
  joinedAt: number;
  lastActive: number;
}

interface RoomSettings {
  allowVoice: boolean;
  allowFileShare: boolean;
  maxParticipants: number;
  isPublic: boolean;
}
```

## 4. Technical Approach

### WebSocket
- 使用现有Collab系统的WebSocket基础设施
- 房间管理：创建/加入/离开
- 消息广播：实时同步消息

### 权限系统
- Owner: 完全控制
- Editor: 可发言、可编辑Persona/Skill
- Viewer: 只读、旁观

### UI Components
- `CollabRoomPanel.tsx` — 协作房间管理
- `ParticipantList.tsx` — 参与者列表
- `InviteModal.tsx` — 邀请链接生成
- `CollabCursor.tsx` — 显示其他人的输入位置

## 5. Constraints
- 浅色主题
- 向后兼容单人模式
- 不破坏现有Collab系统
