# PRJ-20260510-001 — PixelPal V62: 插件市场编辑器

## 概述
V59 已实现插件核心框架（PluginRegistry + IndexedDB 存储 + 3 预置插件）。V62 新增插件编辑器 — 用户可添加自定义插件、编辑已有插件配置、删除用户安装的插件。

## 功能

### P0 — 添加自定义插件
**触发方式**：PluginStore 底部「安装插件」按钮（目前 disabled）→ 点击弹出插件编辑对话框。

**插件编辑表单**：
- 插件 ID（唯一标识，user-前缀，自动生成）
- 名称（emoji + 中文名）
- 版本（默认 1.0.0）
- 作者（默认"自定义"）
- 描述
- 图标（emoji 选择器）
- 权限（fetch/none，多选）
- Actions 列表（可添加/删除多个 action）：
  - Action ID
  - Action 名称
  - 参数列表（逗号分隔）

**保存**：调用 `pluginStorage.savePlugin()`，刷新 PluginStore 列表。

### P1 — 编辑/删除已安装插件
**编辑**：点击已安装插件卡片右上角「编辑」图标 → 弹出预填表单，保存更新。
**删除**：点击「卸载」按钮 → 确认对话框 → 调用 `pluginStorage.deletePlugin()` → 刷新列表。

### P2 — 预置插件不可编辑
预置插件（weather-plugin / calc-plugin / translate-plugin）不显示编辑/删除按钮，仅可启用/停用。

## UI 变更

### 插件编辑对话框
- MUI Dialog，标题「添加插件」或「编辑插件」
- TextField × 7（id/name/version/author/description/icon/permissions）
- Actions 区域：动态添加的 action 行（id + name + params 输入框）
- 底部按钮：取消 / 保存

### PluginStore 卡片变更
- 展开内容底部加「编辑」「卸载」按钮（仅用户安装的插件显示）
- 预置插件仅显示内置标识

### 入口
- PluginStore 底部按钮从 disabled → enabled
