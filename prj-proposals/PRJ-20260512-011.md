# PRD: PixelPal V88 — Provider Deepening

## 1. Concept & Vision

深化Provider抽象层，增加**Token统计、成本追踪、预算控制**。让用户清楚知道每次对话花了多少钱/多少Token，帮助优化使用成本。

## 2. Core Features

### Token统计
- 实时Token计数（prompt + completion）
- 单次对话成本
- 单日/单周/单月累计
- Provider对比统计

### 成本追踪
- 每千Token成本（来自Provider定价）
- 每日成本趋势图
- 月度账单预估
- 成本告警阈值

### 预算控制
- 设置日/周/月预算上限
- 超预算自动提示
- 按Provider分配预算

### Provider性能分析
- 响应时间统计
- 成功率统计
- 平均延迟趋势

## 3. Data Model

```typescript
interface TokenUsage {
  timestamp: number;
  provider: string;
  model: string;
  promptTokens: number;
  completionTokens: number;
  totalTokens: number;
  cost: number; // USD
  responseTime: number; // ms
  success: boolean;
}

interface CostBudget {
  id: string;
  type: 'daily' | 'weekly' | 'monthly';
  limit: number; // USD
  current: number;
  resetAt: number;
  enabled: boolean;
}

interface ProviderStats {
  provider: string;
  totalCalls: number;
  successRate: number;
  avgResponseTime: number;
  totalCost: number;
  totalTokens: number;
}
```

## 5. Technical Changes

### New Services
- `src/services/usage/TokenTracker.ts` — Token计数 + 统计

- `src/services/usage/BudgetManager.ts` — 预算管理
- `src/services/usage/StatsAggregator.ts` — 统计聚合
