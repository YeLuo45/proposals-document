## 1. 背景与目标

当前PixelPal运行在Web端。用户希望能在** Telegram** 和 **Feishu（飞书）** 中使用。

**目标：** 复用现有Agent/Plan/Memory核心逻辑，通过平台适配层支持多入口。

---

## 2. 现状分析

### 2.1 现有核心模块（不修改）
- `agentExecutor.ts` — 任务分解执行
- `memoryManager.ts` — 记忆管理
- `unifiedPluginService.ts` — 插件服务
- `planStore.ts` — 计划状态

### 2.2 平台适配层（新建）
```
src/platform/
  PlatformAdapter.ts    — 统一接口
  WebAdapter.ts         — 现有Web实现（保持原样）
  TelegramAdapter.ts    — NEW
  FeishuAdapter.ts      — NEW
```

### 2.3 PlatformAdapter接口
```typescript
interface PlatformAdapter {
  platform: 'web' | 'telegram' | 'feishu'

  // 消息
  sendMessage(text: string): Promise<void>
  onMessage(handler: (msg: PlatformMessage) => void): void

  // 渲染
  renderMessage(msg: RenderableMessage): void
  renderAgentPanel(state: AgentState): void

  // 用户
  getUserId(): string
  getUsername(): string
}

interface PlatformMessage {
  id: string
  from: string
  text: string
  timestamp: number
  attachments?: Attachment[]
}

interface AgentState {
  runningTaskId: string | null
  taskQueue: Task[]
  memoryCount: number
}
```

## 3. Telegram适配器

### 3.1 依赖
- `npm install telegram-bot-api` 或直接用 `fetch` 调用 Telegram Bot API
- 环境变量：`TELEGRAM_BOT_TOKEN`

### 3.2 实现要点
- 长轮询获取更新：`getUpdates`
- 发送消息：`sendMessage` API
- 支持命令：`/start`, `/agent`, `/status`
- 渲染：Telegram支持 MarkdownV2 格式消息
- 交互按钮：InlineKeyboardMarkup

### 3.3 消息格式映射
```
用户消息 → PlatformMessage → agentExecutor
agentExecutor结果 → Markdown格式 → sendMessage
```

---

## 4. Feishu适配器

### 4.1 依赖
- 环境变量：`FEISHU_APP_ID`, `FEISHU_APP_SECRET`
- 使用飞书开放平台 API

### 4.2 实现要点
- 接收消息：Webhook（需要公网入口）或长轮询
- 发送消息：`im.message.create` API
- 支持卡片消息格式
- 身份验证：tenant_access_token

### 4.3 消息格式映射
```
用户消息 → PlatformMessage → agentExecutor
agentExecutor结果 → 卡片消息 → im.message.create
```

## 5. 路由层

### 5.1 新增入口文件
```
src/index.telegram.ts   — Telegram Bot 独立入口
src/index.feishu.ts     — Feishu Webhook 处理入口
```

### 5.2 Agent引擎初始化（跨平台复用）
```typescript
// src/platform/agentEngine.ts
export function createAgentEngine() {
  const memoryManager = new MemoryManager()
  const executor = new AgentExecutor(unifiedPluginService, memoryManager)
  return { executor, memoryManager }
}
```
