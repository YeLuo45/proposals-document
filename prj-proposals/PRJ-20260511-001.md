# PRD: PixelPal 技能系统 (Skill Framework)

**项目**: pixel-pal-web
**版本**: V77
**日期**: 2026-05-11
**提案ID**: P-20260511-001

## 背景

参考 AstrBot 的 `astrbot/core/skills` 设计，PixelPal 需要一个可复用的 Skill 定义体系。Skill = 预定义工作流模板，用户可一键触发 Agent 执行。

## 目标

实现 Skill Framework：
1. Skill 定义格式（JSON/YAML）
2. Skill 注册表（SkillRegistry）
3. 3个预置 Skill（代码审查官、数据分析师、日程规划师）
4. ChatPanel 触发入口（`/skill` 命令或UI按钮）
5. Skill 执行结果注入上下文

## 架构设计

```
src/services/skills/
  types.ts          — Skill, SkillManifest, SkillResult 接口
  skillRegistry.ts  — 单例注册表（register/get/list/execute）
  presetSkills.ts   — 3个预置Skill定义
  skillRunner.ts    — 执行器（调用agentExecutor）
```

### Skill 接口

```typescript
interface Skill {
  id: string;           // 'code-reviewer'
  name: string;         // '代码审查官'
  description: string;  // '审查代码问题、性能优化建议'
  icon: string;         // emoji: '🔍'
  trigger: string[];    // ['代码审查', '/code-review', 'review code']
  prompt: string;       // 系统级prompt模板
  type: 'reviewer' | 'analyst' | 'planner';
}
```

### SkillRegistry API

```typescript
class SkillRegistry {
  register(skill: Skill): void;
  get(id: string): Skill | undefined;
  list(): Skill[];
  matchSkill(input: string): Skill | undefined;  // 关键词匹配trigger
  execute(skillId: string, context: string): Promise<SkillResult>;
}
```

## ChatPanel 集成

### 方式1：命令触发
用户输入 `/skill code-reviewer` 或 `代码审查` → matchSkill → 执行

### 方式2：UI按钮
ChatPanel 输入框旁新增「技能」按钮 → 弹出 Skill 列表 → 选择执行

## 执行流程

```
用户: "/skill code-reviewer" 或 "帮我审查代码"
  ↓
ChatPanel 检测到 /skill 前缀 或 matchSkill(用户输入)
  ↓
skillRegistry.execute(skillId, userMessage)
  ↓
skillRunner 执行：
  1. 获取skill.prompt
  2. 注入 context（用户消息）
  3. 调用 agentExecutor.executeTask()
  4. 返回 SkillResult
  ↓
将 SkillResult 作为上下文注入 ChatPanel
  ↓
chatCompletionWithTools 生成自然语言回复
```
