# PRD: PixelPal V87 — RAG Deepening

## 1. Concept & Vision

深化V82 Knowledge RAG系统，增加**增量索引**和**语义搜索优化**，让知识库真正成为长期记忆助手。核心：数据持续更新、检索更精准、上下文更丰富。

## 2. Core Features

### 增量索引
- 新文档只索引新增chunk，不全量重建
- 后台增量更新，不阻塞主线程
- 索引进度显示
- 索引历史记录

### 语义搜索优化
- 混合检索：向量 + BM25关键词
- 重排序（Rerank）提升相关性
- 同义词扩展
- 查询改写

### 知识库增强
- 文档自动摘要生成
- 实体识别（人名/地点/概念）
- 知识图谱可视化（简单版）
- 自动标签生成

## 3. Data Model

```typescript
interface IndexedDocument {
  id: string;
  sourceId: string;
  chunks: Chunk[];
  totalChunks: number;
  indexedAt: number;
  status: 'indexing' | 'ready' | 'error';
  summary?: string;
  entities: NamedEntity[];
  tags: string[];
}

interface Chunk {
  id: string;
  content: string;
  embedding?: number[];
  tfidf?: Record<string, number>;
  position: number;
}

interface SearchResult {
  chunk: Chunk;
  score: number;
  rerankScore: number;
  source: KnowledgeSource;
  highlights: string[];
}
```
