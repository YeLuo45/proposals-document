# V30 关系图谱可视化 — PRD

## 背景

已有基础实现：
- `src/services/graph/relationGraph.ts` — 计算节点和边
- `src/components/Graph/RelationGraph.tsx` — Canvas 力导向图渲染
- `src/components/Memory/MemoryPanel.tsx` 行303 — `relationGraphOpen` state + 行573 "查看关系图谱"按钮

当前问题：RelationGraph 组件仅在 Memory 面板有入口，不够突出。力导向图可增强交互性。

## 需求

### P0

1. **Sidebar 入口**：在"团队"（team）面板的 NAV_ITEMS 入口处添加"关系图谱"导航项，点击打开 RelationGraph Dialog

2. **增强边渲染**：
   - 线条粗细 = 消息交流频率（基于 messageCount 平均值归一化，1-5px）
   - 线条颜色 = 亲密度（<40 灰 / 40-70 金 / >70 紫）
   - 悬停高亮 + 线条加粗
   - 已有 hover tooltip 显示两个 persona 头像、平均亲密度、潜在互动热度

3. **增强节点渲染**：
   - 节点大小 = 消息数量（归一化 20-60px）
   - 节点颜色 = persona.theme.primaryColor
   - 悬停时白色边框高亮
   - 显示 emoji + 名字标签
   - 已有 Tooltip 显示消息数、亲密度等级、最后活跃时间

4. **增强布局算法**：
   - 力导向布局（已有 Canvas 2D 实现）
   - 两 persona 间有消息往来时连线，无消息则不连
   - REPULSION_STRENGTH = 5000, ATTRACTION_STRENGTH = 0.01, CENTER_GRAVITY = 0.01, DAMPING = 0.85
   - 节点初始位置：圆形均匀分布
   - 最多 200 次迭代，movement < 0.5 时提前停止

5. **图例 + 标题栏**：
   - 左上角图例：低/中/高亲密度颜色标识
   - 顶部 Chip 显示人格数量
   - 关闭按钮

### P1

6. **点击节点跳转**：点击节点时打开对应 PersonaProfile 或切换到该 persona 的聊天面板

7. **实时更新**：当 personas 或 messages 变化时，图表自动刷新

## 技术方案

- 复用现有 `computeRelationGraph()` service，修改边的计算逻辑：有消息往来的 persona 对才生成边（而非所有排列组合）
- 复用现有 `RelationGraph.tsx` Canvas 渲染，按需增强
- 入口：Sidebar → team 导航 → RelationGraph Dialog
- 或者：单独一个 nav item "graph" 打开 RelationGraph
