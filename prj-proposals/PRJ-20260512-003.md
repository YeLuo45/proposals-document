# PRJ-20260512-003: PixelPal Skill Dev Tools V80

## 1. Concept & Vision

Skill Dev Tools 提供内置的在线 Skill 编辑、调试和预览环境。用户可以像在 IDE 里一样编写 Skill 代码，实时测试执行效果，查看变量状态和输出。降低 Skill 开发门槛，提升调试效率。

## 2. Design Language

沿用 Skill Marketplace 的浅色主题。IDE风格：文件树+编辑器+控制台三栏布局。

## 3. Layout & Structure

### 3.1 Dev Tools Page (route: /skill-dev)

```
┌────────────────────────────────────────────────────────┐
│ [Logo] Skill Dev Tools    [My Skills] [Marketplace]    │
├──────────────┬───────────────────────┬─────────────────┤
│ File Tree    │ Editor                │ Console         │
│              │                       │                 │
│ ├─ presets/  │ // Skill: EggTimer   │ > Running...    │
│ │  └─ *.ts   │ const run = async () │ > Step 1: OK    │
│ ├─ custom/   │                       │ > Output: "3min"│
│ │  └─ *.ts   │                       │                 │
│ └─ chains/   │                       │                 │
│              ├───────────────────────┤                 │
│ [+ New]      │ Preview / Test Panel │ [Clear] [Debug] │
└──────────────┴───────────────────────┴─────────────────┘
```

### 3.2 Console Panel

- Timestamped log entries
- Color-coded: info (blue), success (green), error (red), warn (yellow)
- Expandable object/JSON inspection
- Variable inspector showing current vars state

## 4. Features & Interactions

### 4.1 Code Editor

- Monaco Editor (VSCode内核) via `@monaco-editor/react`
- TypeScript syntax highlighting
- Auto-completion for skill API (types.ts definitions)
- Real-time validation (red underlines for errors)
- Line numbers, minimap

### 4.2 Skill File Operations

```typescript
// Skill file format (TypeScript)
export const skill = {
  id: 'my-custom-skill',
  name: 'My Skill',
  description: '...',
  // ... SkillDefinition fields
  
  // Execution function
  async execute(context: SkillExecutionContext): Promise<SkillExecutionResult> {
    const { triggerMessage, parsedParams } = context;
    // Custom logic
    return {
      success: true,
      response: 'Result',
      durationMs: 100,
    };
  }
};
```

### 4.3 Debug Panel

- **Input**: Editable test input message
- **Context**: Editable context JSON (personaId, metadata, etc.)
- **Run**: Execute skill with test input
- **Step Through**: (optional) pause after each step

### 4.4 Console Output

- Skill execution logs streamed in real-time
- JSON response pretty-printed
- Error stack traces with file:line links
- Variable state at each step

### 4.5 File Tree

- Preset skills (read-only)
- Custom skills (editable)
- Chains (editable)
- Right-click: rename, delete, duplicate
- Drag-drop to reorder

### 4.6 Save & Publish

- Save to custom skills (IndexedDB)
- "Test & Install" → saves and enables immediately
- Export as JSON

## 6. Technical Approach

### 6.1 New Dependencies

```json
{
  "@monaco-editor/react": "^4.6.0",
  "monaco-editor": "^0.44.0"
}
```

### 6.2 New Files

- `src/pages/SkillDevPage.tsx` — main page
- `src/components/SkillDev/FileTree.tsx` — file browser
- `src/components/SkillDev/CodeEditor.tsx` — Monaco wrapper
- `src/components/SkillDev/ConsolePanel.tsx` — output console
- `src/components/SkillDev/DebugPanel.tsx` — test runner
- `src/components/SkillDev/SkillPreview.tsx` — preview card
- `src/services/skilldev/fileService.ts` — virtual file system for skill code
- `src/data/skillCodeTemplates.ts` — starter templates

### 6.3 Update Files

- `src/App.tsx` — add /skill-dev route
- `src/components/Skill/SkillPanel.tsx` — add "Dev Tools" button linking to /skill-dev

### 6.4 Virtual File System

Skills stored as code strings (TypeScript source) in localStorage, compiled/eval'd at runtime via `new Function()` + TypeScript compiler or direct execution.

### 6.5 Security

- Skill code runs in limited scope (no DOM, no fetch to external APIs except configured endpoints)
- Timeout on execution (max 30s)
- Async function wrapping required

## 7. Starter Templates

1. **Empty Skill** — minimal SkillDefinition structure
2. **API Caller** — skill that calls external API
3. **Text Processor** — transform/input parsing skill
4. **Chain Step** — lightweight step for use in chains
