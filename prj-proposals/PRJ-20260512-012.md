# PRD: PixelPal V89 — Agent×Skill Integration

## 1. Concept & Vision

让Agent和Skill真正协同工作。Agent能调用Skill增强能力，Skill执行结果反馈给Agent形成闭环。复杂任务由Agent规划 → Skill执行 → Agent整合 → Skill再执行，形成递进式问题解决。

## 2. Core Features

### Agent调用Skill
- Agent执行时自动匹配可用Skill
- Skill作为Agent的工具扩展
- Skill执行结果注入Agent上下文
- Skill执行失败时Agent自动重试或绕过

### Skill反馈Agent
- Skill执行后生成结构化结果摘要
- 关键信息提取 + 置信度评分
- 建议下一步行动
- 异常情况告警

### Skill执行器集成
- `AgentExecutor` 调用 `SkillRunner`
- Skill优先级：高/中/低
- Skill超时控制
- Skill并行执行

### 协作场景
- Research任务：Agent规划 → WebSearch Skill → 知识库RAG Skill → 汇总
- Coding任务：Agent规划 → CodeSkill → ReviewSkill → 重试优化
- Creative任务：Agent规划 → ImageSkill → 文案Skill → 多Agent投票

## 3. Data Model

```typescript
interface SkillExecution {
  id: string;
  skillId: string;
  agentId: string;
  taskId: string;
  input: unknown;
  output?: unknown;
  error?: string;
  status: 'pending' | 'running' | 'completed' | 'failed';
  startedAt: number;
  completedAt?: number;
  confidence?: number;
  suggestions?: string[];
}

interface SkillResult {
  success: boolean;
  data: unknown;
  summary: string;
  confidence: number; // 0-1
  nextActions: string[];
  metadata: Record<string, unknown>;
}
```
