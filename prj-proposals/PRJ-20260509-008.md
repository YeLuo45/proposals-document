## 1. 背景与目标

V63实现了语音情感检测（EmotionCurve），能识别用户情绪。但目前只是**被动展示**，没有主动响应。

**目标：** 当检测到特定情绪时，Agent自动触发对应行为（安慰/鼓励/安静/活跃/专注建议）。

---

## 2. 现状分析

### 2.1 情感数据（V63）
- `EmotionCurve` 组件：实时显示情绪曲线（愉悦/激活/支配三维）
- `emotionEngine.ts`：情绪识别逻辑
- 情绪类型：joy, sadness, anger, fear, surprise, neutral

### 2.2 当前Agent行为（V64-V67）
- `agentExecutor.ts`：任务分解执行
- `memoryManager.ts`：记忆上下文
- 行为触发：用户显式发指令

### 2.3 缺失环节
```
情绪检测 → 无联动 → Agent行为独立
```

## 3. 功能设计

### 3.1 情绪-行为映射表

```typescript
// src/services/emotion/emotionBehaviorMap.ts

interface EmotionAction {
  emotion: EmotionType
  confidenceThreshold: number  // 最低置信度
  action: 'comfort' | 'encourage' | 'calm' | 'activate' | 'focus_suggest' | 'none'
  message: string  // 触发的消息
  priority: number  // 优先级（高情绪覆盖低情绪）
}

const EMOTION_BEHAVIOR_MAP: EmotionAction[] = [
  { emotion: 'sadness', confidenceThreshold: 0.6, action: 'comfort', message: '我感觉到你有些低落，想聊聊吗？', priority: 3 },
  { emotion: 'anger', confidenceThreshold: 0.6, action: 'calm', message: '我理解你有些生气，深呼吸一下？', priority: 4 },
  { emotion: 'fear', confidenceThreshold: 0.5, action: 'calm', message: '别担心，我在这里陪你。', priority: 4 },
  { emotion: 'joy', confidenceThreshold: 0.7, action: 'encourage', message: '你看起来很开心！继续保持~', priority: 1 },
  { emotion: 'surprise', confidenceThreshold: 0.5, action: 'focus_suggest', message: '是什么让你惊讶了？需要我帮忙分析吗？', priority: 2 },
  { emotion: 'neutral', confidenceThreshold: 0.8, action: 'none', message: '', priority: 0 },
]
```

### 3.2 EmotionBehaviorEngine

```typescript
// src/services/emotion/EmotionBehaviorEngine.ts

class EmotionBehaviorEngine {
  private lastEmotion: EmotionType | null = null
  private lastTriggerTime = 0
  private cooldownMs = 30000  // 30秒内不重复触发

  // 核心方法：给定当前情绪，返回应执行的行为
  getRecommendedAction(emotion: EmotionType, confidence: number): EmotionAction | null {
    if (this.isInCooldown()) return null
    const action = EMOTION_BEHAVIOR_MAP.find(m => m.emotion === emotion && confidence >= m.confidenceThreshold)
    if (action && action.action !== 'none') {
      this.lastEmotion = emotion
      this.lastTriggerTime = Date.now()
    }
    return action || null
  }

  private isInCooldown(): boolean {
    return Date.now() - this.lastTriggerTime < this.cooldownMs
  }

  // 设置冷却时间（可通过配置调整）
  setCooldown(ms: number): void {
    this.cooldownMs = ms
  }
}

export const emotionBehaviorEngine = new EmotionBehaviorEngine()
```

### 3.3 Agent集成

修改 `agentExecutor.ts` 或新增 `src/services/agent/emotionAwareExecutor.ts`：

```typescript
// 在任务执行循环中加入情感检查
async executeTask(taskId: string) {
  // ... 现有逻辑 ...

  // 检查是否有待处理的情感行为
  const currentEmotion = emotionEngine.getCurrentEmotion()  // 假设有这接口
  if (currentEmotion) {
    const action = emotionBehaviorEngine.getRecommendedAction(
      currentEmotion.type,
      currentEmotion.confidence
    )
    if (action) {
      // 通过platformAdapter发送情感响应消息
      platformAdapter.sendMessage(action.message)
      // 可选：记录到记忆
      memoryManager.add({
        type: 'emotion_response',
        content: `情绪响应: ${action.action} - ${action.message}`,
        importance: 'medium'
      })
    }
  }
}
```

## 4. 非功能需求

- 情感响应消息不影响正常任务执行（异步，不阻塞）
- 用户可配置关闭情感联动
- 冷却机制防止重复触发
- 与平台无关（通过 PlatformAdapter 接口发送）
