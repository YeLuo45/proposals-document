## Context

V7 完成收藏夹管理。V8 继续 A 方向：批量操作（批量删除/收藏历史）+ 社区分享（生成分享链接）。

## Requirements

### R1: 批量选择模式
在 history.js 增加批量选择：
- 页面顶部出现"全选"复选框 + "已选 N 项" + 批量操作按钮
- 每条历史记录左侧增加复选框
- 批量操作：批量删除、批量收藏到专辑

### R2: 批量删除
点击"批量删除" → 确认弹窗"确认删除 N 项？" → 确认后删除所选。

### R3: 批量收藏
点击"批量收藏" → 弹出专辑选择弹窗 → 批量添加到同一专辑。

### R4: 生成分享链接（简单版）
在每条历史记录增加"分享"按钮，点击生成一个基于 base64 data 的 data URL 分享信息（图片转 base64，音乐/语音转 base64）。显示"已复制到剪贴板"提示。
