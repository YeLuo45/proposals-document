## Context

ai-creator-h5 当前使用原生 JS + Vite SPA，UI 较基础（单色背景 + 简单卡片）。参考 nanobot-design 的设计语言（深色主题 + 橙/青品牌色 + glass-morphism）进行视觉升级。

## Requirements

### R1: 暗色主题
全局 CSS 变量引入深色主题：
```css
--bg-page: #0A0A0F;
--bg-card: #12121A;
--bg-surface: #1A1A24;
--text-primary: #F0F0F5;
--text-secondary: #A0A0B0;
--border: #2A2A3A;
```

### R2: 品牌色渐变
- Primary: `#f97316` (orange)
- Secondary: `#06b6d4` (cyan)
应用于：按钮渐变背景、标题渐变、hover 发光效果

### R3: Glass-morphism 导航栏
```css
background: rgba(18, 18, 26, 0.8);
backdrop-filter: blur(12px);
border-bottom: 1px solid rgba(255,255,255,0.05);
```

### R4: 卡片动效
- Hover: box-shadow 发光（orange glow）
- 过渡: transition 0.2s ease

### R5: 页面过渡
Hash 路由切换时添加 fade-in 动画

## Files to modify
- `src/styles/global.css` — CSS 变量 + 暗色主题 + glass-morphism
- `src/app.js` — 路由切换动画
