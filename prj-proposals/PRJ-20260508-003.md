# PRJ-20260508-003 — PixelPal V56: 语义搜索历史对话

## 概述
基于 Embedding 向量化的语义搜索——用户输入自然语言查询，AI 从历史消息中检索最相关的片段。

## 功能

### 核心流程
1. 消息写入 IndexedDB 时，同步调用 Embedding API 生成向量
2. 向量 + 原文元数据存入 IndexedDB（新建 `embeddings` store）
3. 用户点击"搜索历史"→ 输入自然语言 query
4. query 向量化 → 在向量库中 cosine similarity top-k 检索 → 展示相关消息 + 时间

### 技术细节

**Embedding API**：
- 使用 MiniMax Embedding API（`/api/embedding`）或 OpenAI-compatible endpoint
- 模型：text-embedding-v2 或兼容模型
- 单条消息内容 → 向量（dim 1536 或 1024）

**向量存储**：
- IndexedDB 新增 `embeddings` objectStore
- 结构：`{ id, messageId, personaId, content, embedding: Float32Array, timestamp }`
- 使用 `messageId` 关联原始消息

**检索**：
- 计算 query 与每条消息的 cosine similarity
- 返回 top-k（如 5 条）最相关消息
- 在 ChatPanel 或 MemoryPanel 展示结果

**UI**：
- ChatPanel toolbar 添加"🔍 搜索历史"图标
- 点击弹出 Dialog，输入 query
- 下方展示检索结果列表（消息内容 + 时间 + 相似度分）
- 点击结果可定位到原消息（或复制内容）
