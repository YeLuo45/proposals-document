## 1. 背景

当前多Agent系统已完整（Orchestrator + Executor + Reviewer），但用户无法主动触发多Agent流程。

**目标：** 在ChatPanel添加触发机制，让用户通过特定指令（如"/multi"或"@all"）启动多Agent协作流程。

---

## 2. 功能设计

### 2.1 触发指令

- `/multi <任务描述>` — 启动多Agent协作
- `/single <任务描述>` — 使用传统单Agent模式
- 自动检测：如果消息包含"帮我写代码"或"帮我检查"等关键词，自动触发多Agent

### 2.2 创建MultiAgentTrigger

```typescript
// src/hooks/useMultiAgentTrigger.ts

import { useCallback } from 'react'
import { agentBus } from '../services/agents/agentBus'
import { orchestratorAgent } from '../services/agents/orchestratorAgent'

export function useMultiAgentTrigger() {
  const triggerMultiAgent = useCallback((message: string) => {
    // 通过AgentBus发送任务给Orchestrator
    agentBus.send({
      from: 'ui',
      to: 'orchestrator',
      type: 'task',
      payload: { message },
      timestamp: Date.now(),
    })

    return true
  }, [])

  const parseCommand = useCallback((input: string): { mode: 'multi' | 'single' | 'auto'; message: string } => {
    const trimmed = input.trim()

    // /multi 命令
    if (trimmed.startsWith('/multi ')) {
      return { mode: 'multi', message: trimmed.slice(7) }
    }

    // /single 命令
    if (trimmed.startsWith('/single ')) {
      return { mode: 'single', message: trimmed.slice(8) }
    }

    // 自动检测关键词
    const multiKeywords = ['写代码', '代码审查', '检查代码', '帮我', '多个任务', '分解']
    const shouldMulti = multiKeywords.some(k => trimmed.includes(k))

    return {
      mode: shouldMulti ? 'multi' : 'single',
      message: trimmed,
    }
  }, [])

  return {
    triggerMultiAgent,
    parseCommand,
  }
}
```

### 2.3 ChatPanel集成

```typescript
// src/components/ChatPanel/ChatPanel.tsx 修改

// 在组件内添加：
const { triggerMultiAgent, parseCommand } = useMultiAgentTrigger()

// 修改handleSend函数：
const handleSend = async (message: string) => {
  const { mode, message: processedMsg } = parseCommand(message)

  if (mode === 'multi') {
    // 触发多Agent流程
    triggerMultiAgent(processedMsg)
    // 显示提示
    addMessage({
      id: Date.now().toString(),
      text: `[多Agent模式] 已启动协作流程处理: "${processedMsg}"`,
      from: 'system',
      timestamp: Date.now(),
    })
    return
  }

  // 单Agent模式走原有逻辑
  // ... 原有handleSend逻辑
}
```

## 3. 触发流程图

```
用户输入 "/multi 帮我写一个登录功能"
    ↓
parseCommand() → { mode: 'multi', message: '帮我写一个登录功能' }
    ↓
triggerMultiAgent() → agentBus.send({ to: 'orchestrator', ... })
    ↓
OrchestratorAgent.processUserRequest()
    ↓
decomposeTask() → [code-task, review-task]
    ↓
ExecutorAgent + ReviewerAgent 并行执行
    ↓
结果汇总 → 系统消息显示
```

5. 系统消息显示协作状态
