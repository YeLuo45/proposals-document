## 1. 背景

当前存在两套Agent系统：
1. **V64 AgentExecutor** — 单一Agent执行器，有完整的任务分解和执行能力
2. **多Agent系统** — OrchestratorAgent + ExecutorAgent + ReviewerAgent，但ExecutorAgent.simulateExecution是stub

**目标：** 让多Agent系统的ExecutorAgent真正调用V64 AgentExecutor，实现完整的协作执行能力。

---

## 2. 功能设计

### 2.1 修改ExecutorAgent

```typescript
// 修改 src/services/agents/executorAgent.ts

// 替换 simulateExecution 方法，调用真实的 agentExecutor

import { agentExecutor } from '../agent/agentExecutor'
import type { Task } from './types'

// 在 simulateExecution 中：
private async simulateExecution(task: Task): Promise<unknown> {
  // 复用 V64 agentExecutor 的执行能力
  const result = await agentExecutor.executeTask({
    goal: task.description,
    type: task.type,
    inputs: task.inputs,
  })

  return result
}
```

### 2.2 添加orchestratorAgent初始化入口

```typescript
// 修改 src/services/agents/init.ts

import { orchestratorAgent } from './orchestratorAgent'
import { executorAgent } from './executorAgent'
import { reviewerAgent } from './reviewerAgent'
import { agentRegistry } from './agentRegistry'

export function initMultiAgentSystem(): void {
  console.log('[MultiAgent] Initializing...')

  // 确保默认Agent已注册（executorAgent/reviewerAgent构造时会自动注册）
  void executorAgent
  void reviewerAgent

  // 注册orchestrator（不自动注册，由用户触发）
  if (!agentRegistry.get('orchestrator')) {
    agentRegistry.register({
      id: 'orchestrator',
      name: '任务编排Agent',
      type: 'orchestrator' as any,
      capabilities: ['task_decomposition', 'agent_selection', 'progress_tracking'],
    })
  }

  console.log('[MultiAgent] Ready - registered agents:', agentRegistry.list().map(a => a.id).join(', '))
}
```

### 2.3 App.tsx集成（可选）

在 `src/App.tsx` 或入口处添加初始化调用：
```typescript
useEffect(() => {
  import('./services/agents/init').then(({ initMultiAgentSystem }) => {
    initMultiAgentSystem()
  })
}, [])
```

## 3. 架构图

```
OrchestratorAgent
    ↓ 分解任务
    ↓
ExecutorAgent
    ↓ 调用
    ↓
AgentExecutor (V64) ← 复用现有能力
    ↓ 执行
    ↓
AgentBus ← 结果返回
    ↓
OrchestratorAgent → 汇总
```
