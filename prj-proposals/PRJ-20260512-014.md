# PRD: PixelPal V91 — Mobile Deepening

## 1. Concept & Vision

在V86 Mobile Adaptation基础上深化，增加**手势导航**、**性能优化**和**PWA支持**，让移动端体验接近原生App。

## 2. Core Features

### 手势导航
- 右滑返回上一层
- 双指捏合缩放（图片/图表）
- 长按显示快捷操作
- 惯性滚动 + 边界回弹

### 性能优化
- 虚拟列表：长消息列表只渲染可见项
- 图片懒加载：滚动到可见区再加载
- 组件懒加载：非关键组件异步导入
- 防抖/节流：频繁操作优化

### PWA支持
- Service Worker：离线缓存
- Web App Manifest：可添加到主屏幕
- 推送通知：消息提醒
- 后台同步：网络恢复后同步数据

### 移动端增强
- 触摸反馈：按钮点击波纹效果
- 键盘适配：输入框被键盘遮挡时上移
- 方向切换：横屏/竖屏自适应
- 夜间模式：跟随系统设置

## 3. Technical Changes

### Performance
- `src/hooks/useVirtualList.ts` — 虚拟列表
- `src/hooks/useLazyLoad.ts` — 图片懒加载
- `src/hooks/useDebounce.ts` — 防抖
- `src/utils/lazyImport.tsx` — 组件懒加载

### Gesture
- `src/hooks/useSwipeBack.ts` — 右滑返回
- `src/hooks/usePinchZoom.ts` — 双指缩放
- `src/hooks/useLongPress.ts` — 长按

### PWA
- `public/manifest.json` — Web App Manifest
- `public/sw.js` — Service Worker
- `src/components/PWA/InstallPrompt.tsx` — 安装提示

### UI Enhancements
- 触摸波纹效果
- 键盘适配处理
- 方向检测

## 4. Constraints
- 不破坏桌面端体验
- 浅色主题延续
- 向后兼容V86
