**Proposal ID**: P-20250416-003
**版本**: v1.0
**日期**: 2026-04-16
**Owner**: 小墨

---

## 1. 概述

### 1.1 产品背景

开发一款面向大众市场的 Android 计算器应用，基于 React Native 构建，提供科学计算、单位转换和汇率换算三大核心功能。用户群体为日常需要计算需求的普通用户。

### 1.2 目标

- 打造一款功能齐全、界面简洁的通用计算器
- 支持科学计算功能（满足学生、工程师等进阶用户）
- 内置常用单位转换和实时汇率换算
- 通过 Google Play 或直接分发 APK 面向大众

## 2. 功能规范

### 2.1 基础计算

| 功能 | 描述 |
|------|------|
| 四则运算 | 加减乘除，支持连续运算 |
| 括号 | 支持嵌套括号，优先级正确 |
| 百分比 | 支持 % 运算 |
| 正负切换 | 一键切换正负数 |
| 清除 | AC 键清除全部，C 键清除当前输入 |
| 退格 | 删除最后一个字符 |
| 小数点 | 支持任意小数运算 |
| 结果复制 | 一键复制计算结果 |

### 2.2 科学计算

| 功能 | 描述 |
|------|------|
| 三角函数 | sin, cos, tan 及反三角函数 |
| 对数 | log（底10）, ln（自然对数） |
| 指数 | e^x, 10^x, x^y, x^2, x^3 |
| 阶乘 | n! |
| 开方 | √x, ∛x |
| 幂运算 | x^y |
| 圆周率/自然常数 | π, e |
| 倒数 | 1/x |
| 绝对值 | |x| |

### 2.3 单位转换

覆盖以下类别，每类至少包含5种常用单位：

| 类别 | 单位示例 |
|------|----------|
| 长度 | 米、厘米、毫米、英寸、英尺、码、公里、英里 |
| 重量 | 千克、克、毫克、磅、盎司、吨 |
| 温度 | 摄氏度、华氏度、开尔文 |
| 面积 | 平方米、平方厘米、平方公里、亩、英亩 |
| 体积 | 升、毫升、加仑（美）、夸脱、立方米 |
| 速度 | 米/秒、公里/小时、英里/小时、节 |

### 2.4 汇率换算

| 功能 | 描述 |
|------|------|
| 支持货币 | 人民币（CNY）、美元（USD）、欧元（EUR）、日元（JPY）、英镑（GBP）、韩元（KRW）、港币（HKD）等主要货币 |
| 汇率来源 | 启动时从公开 API 获取实时汇率 |
| 离线支持 | 上次获取的汇率缓存到本地，断网时使用缓存汇率 |
| 货币切换 | 双向快捷切换，输入即换算 |

## 3. UI/UX 规范

### 3.1 整体风格

- **设计语言**: Material Design 3
- **主题**: 支持浅色/深色模式跟随系统
- **配色方案**:
  - 主色: #4CAF50（绿色，科学计算器常用色）
  - 背景: 浅色模式 #FAFAFA，深色模式 #121212
  - 按键: 数字键 #FFFFFF（浅色）/ #2D2D2D（深色），运算符键 #E8F5E9（浅色）/ #1B5E20（深色）
  - 等号键: 主色同色系渐变

### 3.2 布局结构

```
┌─────────────────────────────┐
│  显示区域（计算结果/表达式）  │  ← 顶部 20%
├─────────────────────────────┤
│  模式切换：基础/科学/转换    │  ← 固定标签栏
├─────────────────────────────┤
│                             │
│       按键区域               │  ← 底部 80%
│                             │
└─────────────────────────────┘
```

### 3.3 按键布局

**基础模式（4×5网格）**:
```
[ AC ] [ C  ] [ %  ] [ ÷  ]
[ 7  ] [ 8  ] [ 9  ] [ ×  ]
[ 4  ] [ 5  ] [ 6  ] [ -  ]
[ 1  ] [ 2  ] [ 3  ] [ +  ]
[ ±  ] [ 0  ] [ .  ] [ =  ]
```

**科学模式（折叠或滚动扩展）**:
在基础模式上方增加一行或两行科学函数键

**单位转换模式**:
- 顶部：类别选择器（横向滚动标签）
- 中部：两个输入框 + 对应单位选择器
- 底部：常用快捷换算

### 3.4 交互规范

- 按键触摸反馈：触感震动（可选）+ 视觉高亮
- 计算结果自动格式化：千分位分隔符
- 长数字显示：科学计数法自动切换
- 计算历史：最近10条记录可快速复用

## 4. 技术规范

### 4.1 技术栈

| 类别 | 选择 |
|------|------|
| 框架 | React Native 0.76+ (CLI) |
| 语言 | TypeScript |
| 状态管理 | React Context + useReducer |
| UI 组件 | React Native Paper (MD3) |
| 动画 | React Native Reanimated |
| 本地存储 | AsyncStorage（汇率缓存、历史记录） |
| 汇率 API | 公开免费 API（如 exchangerate-api.com） |

### 4.2 项目结构

```
CalculatorApp/
├── src/
│   ├── components/        # 可复用组件
│   ├── screens/           # 页面
│   ├── utils/             # 计算逻辑、格式化
│   ├── services/          # API 服务
│   ├── hooks/             # 自定义 Hooks
│   ├── context/            # 全局状态
│   └── constants/          # 常量、配置
├── android/               # Android 原生项目
└── App.tsx
```

### 4.3 构建目标

- **最低 Android 版本**: API 24 (Android 7.0)
- **APK 签名**: Debug 签名（开发测试用）
- **输出**: `android/app/build/outputs/apk/debug/app-debug.apk`

## 5. 非功能性需求

| 需求 | 描述 |
|------|------|
| 性能 | 基础计算 < 16ms（60fps），科学计算 < 100ms |
| 兼容性 | 适配主流 Android 设备（6寸~10寸屏） |
| 无障碍 | 支持 TalkBack 屏幕阅读 |
| 权限 | 仅需网络权限（汇率获取） |
| 包体积 | APK < 30MB |

## 6. 验收标准

### 6.1 功能验收

- [ ] 基础四则运算正确（加减乘除、括号、连续运算）
- [ ] 科学计算函数结果与标准数学库一致（精度到6位小数）
- [ ] 单位转换覆盖所有规定类别和单位
- [ ] 汇率换算正确，实时汇率可获取
- [ ] 离线时使用缓存汇率不崩溃

### 6.2 UI/UX 验收

- [ ] 浅色/深色模式正常切换
- [ ] 按键布局符合规范，触摸区域 >= 48dp
- [ ] 数字显示自动格式化（千分位、科学计数法）
- [ ] 触控反馈流畅，无明显卡顿

### 6.3 构建验收

- [ ] `npm run build` 或 `gradlew assembleDebug` 成功
- [ ] 生成的 APK 可在 Android 7.0+ 设备安装
- [ ] APK 可在独立环境运行（不依赖 Metro bundler）
